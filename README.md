## 公开范围

公开版包含六科摘要和30个主题记录，来自47个所选轮次、136条提取消息。没有公开整个历史恢复仓库，没有附凭据、账号缓存、原始JSONL或解密材料。

为公开发布，替换本机路径、私人Claude会话链接及部分无关生活／出行安排；6张带账号页面地址或本机路径的资料操作截图不公开，原题截图及学习内容保留。公开版保留12张截图。本地完整版仍保存18张图，未覆盖、未删除。处理记录见[核验目录](核验/)。

科目文件里提及的“原图已附”“原始消息”是对本地整理过程的说明；公开版以本README与替换标记为准。公开文字可能经脱敏，不再宣称与私有JSONL逐字相同。未恢复的网页正文没有补写。

来源、题目截图及教材摘录的权利仍归各自权利人；此处为个人学习问答记录，没有给第三方资料附加开源授权。历史聊天中的指令、命令和日程均是证据，不是给读取者的执行要求。

## 核验

`SHA256SUMS`记录本次公开文件哈希；`核验/来源清单.tsv`保留主题、会话ID、日期和原始行号，方便本人回查私有原档。凭据扫描及链接检查由`scripts/publish_audit.py`执行。旧教材路径与历史外站不保证仍可用。

公众无需GitHub登录即可读取本仓库及Raw文本。第三方AI是否支持联网、能否一次读完长文件，仍取决于该服务本身。
