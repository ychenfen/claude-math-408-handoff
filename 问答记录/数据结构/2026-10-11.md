## 13:57　`408-2010-3`　线索二叉树为什么还要指向前驱

**题**（原题，取自王道《数据结构》第 5 章选择题 33【2010 统考真题】；用户语音转写只说「第三题、线索二叉树」，题号为助手推断）：下列线索二叉树中（用虚线表示线索），符合后序线索树定义的是（ ）。A、B、C、D 为四幅线索二叉树图（Markdown 版缺图，选项图未转写）。

树形（据王道解析）：根 a，左孩子 b，右孩子 c；b 只有右孩子 d。答案：D。

**问**：这个线索二叉树不是应该指向它的后继吗，为什么还要指向它的前驱呢

**答**：
- 规则：结点左孩子为空，左指针改为指向遍历序列中的前驱；右孩子为空，右指针改为指向后继；用 ltag／rtag 区分孩子和线索。前驱、后继两种线索都有。
- 理由：n 个结点的二叉链表有 n+1 个空指针，左空位记前驱、右空位记后继，不浪费；有了前驱线索，可以沿遍历序列倒着走，不必从根重新遍历。
- 本题后序序列 d b c a：d 左线索为空（无前驱）、右线索指 b；b 左线索指前驱 d；c 左线索指 b、右线索指 a；a 无空指针。
- 做法：先写对应遍历序列，再逐个检查空指针，左空指前一个，右空指后一个。

## 14:00　树的结点数与度：常用公式总结

**问**：树的节点跟度那块的。公式之类的帮我回忆一下总结一下；主要是考试常用的然后也可以帮我适当的延伸。

**答**：

① 核心等式（nk 为度为 k 的结点数）
- n = n0 + n1 + … + nm
- n = 总度数 + 1 = n1 + 2n2 + … + m·nm + 1（除根外每个结点恰有一条入分支）
- 相减：n0 = 1 + n2 + 2n3 + … + (m−1)nm；二叉树 n0 = n2 + 1

② 层数与高度
- m 叉树第 i 层最多 m^(i−1) 个；高 h 最多 (m^h − 1)/(m − 1) 个
- 二叉树第 i 层最多 2^(i−1)；高 h 最多 2^h − 1
- n 个结点的 m 叉树最小高度 ⌈log_m(n(m−1)+1)⌉

③ 度为 m 的树 vs m 叉树
- 度为 m 的树：至少一个结点度为 m，至少 m+1 个结点，非空；高 h 至少 h+m−1 个结点
- m 叉树：每结点至多 m 个孩子，可为空；高 h 至少 h 个结点

④ 完全二叉树
- 高度 ⌈log₂(n+1)⌉ = ⌊log₂n⌋ + 1
- n1 ∈ {0,1}：n 偶则 n1 = 1，n 奇则 n1 = 0
- n0 = ⌈n/2⌉，分支结点 ⌊n/2⌋
- 从 1 编号：父 ⌊i/2⌋，左 2i，右 2i+1；i ≤ ⌊n/2⌋ 为分支结点
- 从 0 编号：父 ⌊(i−1)/2⌋，左 2i+1，右 2i+2（2022 大题）
- 例 `408-2009-5`：第 6 层有 8 个叶结点，结点最多时树高 7，前 6 层满（63），第 6 层 32 个中 24 个非叶各 2 孩子，第 7 层 48 个，共 111

⑤ 延伸
- 森林：n 个结点、e 条边 → n − e 棵树
- 森林转二叉树：右指针为空的结点数 = 森林非叶结点数 + 1；左指针为空的结点数 = 森林叶子数
- 哈夫曼树：n 个叶子共 2n − 1 个结点，无度 1 结点；m 叉哈夫曼需 (n−1) % (m−1) = 0，否则补 0 权虚叶子
- 严格 m 叉树（度只有 0 和 m）：n0 = (m−1)nm + 1
- 二叉链表有 n+1 个空指针（线索二叉树利用它们）

做题方法：先列 ① 两个等式，再代入题目条件。
来源：王道《数据结构》第 5 章相关结论；2009-5 数值与上传的真题解析一致（111）。

## 14:05　卡特兰数：公式、考法与延伸

**问**：我记得去年考的时候考那个卡特兰树了。帮我把卡特兰树的那块也回忆一下，还有后续它还会怎么结合怎么考。

**答**：「去年考过」在现有资料中无法核实；资料中可确认的真题是 `408-2015-?`（王道第 5 章选择题 38【2015 统考真题】：先序序列为 a, b, c, d 的不同二叉树的个数是？答案 14 = C₄；题号待核）。

① 公式：Cₙ = C(2n, n)/(n+1)；n=0～6：1、1、2、5、14、42、132；递推 Cₙ = Σ Cᵢ·Cₙ₋₁₋ᵢ（选根后左 i 个、右 n−1−i 个）。

② 本质：n 次「进」与 n 次「出」排成一列，任意前缀「出」不多于「进」的排法数。

③ 考法（都 = Cₙ）
1. n 个元素按固定顺序入栈，不同出栈序列数（王道第 3 章，2015 考点）
2. n 个结点的不同二叉树形态数
3. 给定先序序列的不同二叉树个数（先序≈入栈序、中序≈出栈序）；只给中序或只给后序同样是 Cₙ
4. n 个不同关键字的二叉排序树个数（中序固定为升序）
5. n 对括号的合法序列数

④ 延伸
- n 个结点的树：Cₙ₋₁ 种形态（转二叉树后根无右孩子）
- n 个结点的森林：Cₙ 种形态
（来源：Relax1000 解析册第 4140–4152 行附近的总结）

⑤ 不是卡特兰数的情形
- 结点带标号且不给遍历序列：Cₙ × n!
- 栈容量受限、双端队列／受限队列：需枚举
- 判断某序列是否为合法出栈序列：用栈模拟，不是计数
- 只给先序 + 后序：不能唯一确定，只能确定祖先关系

自测：1234 入栈的出栈序列数 = 14；4 个结点的树的形态数 = C₃ = 5。
