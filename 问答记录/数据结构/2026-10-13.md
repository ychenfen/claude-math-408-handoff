| 错法 | 跑出来的结果 |
|---|---|
| 顺序表插入从前往后挪 | 1 3 5 6 6（8 丢了） |

## 14:48　`408-2010-42`　循环左移：在原代码上改错

**题**（2010 年 408 第 42 题；王道《数据结构》2.2 综合应用题 10）：设将 n（n > 1）个整数存放到一维数组 R 中。设计一个在时间和空间两方面都尽可能高效的算法。将 R 中保存的序列循环左移 p（0 < p < n）个位置，即将 R 中的数据由 (X0, X1, …, Xn−1) 变换为 (Xp, Xp+1, …, Xn−1, X0, X1, …, Xp−1)。要求：1）给出算法的基本设计思想。2）根据设计思想，采用 C 或 C++ 或 Java 语言描述算法，关键之处给出注释。3）说明你所设计算法的时间复杂度和空间复杂度。

**问**：10 年这个代码我错在哪里告诉我，我改改，在我基础上改为正确的。

**原代码**（按 10-10 记录转写，答题卡照片含姓名未公开）：

```c
void reverse(int i, int j){
    for (int i = 0; i < n; i++, j--){
        a[t] = a[i]; a[i] = a[j]; a[j] = a[t];
    }
}
reverse(0, n-1); reverse(0, n-p); reverse(n-p+1, n-1);
```

**错在哪**（gcc 跑过，n = 8、p = 3）：
1. for 里又写了 `int i = 0`：新定义了一个 i，参数 i 被盖掉，每次都从 0 开始。改成不重新定义。
2. 条件 `i < n`：换到一半后又换回去，整体逆置跑完数组原样不变（实测 1 2 3 4 5 6 7 8 没动）。改成 `i < j`。
3. 交换用 `a[t]` 当临时：t 没定义，而且借用数组里一格会覆盖数据。改成 `int t = a[i]; a[i] = a[j]; a[j] = t;`。
4. 两段分界差 1：整体逆置后前 n−p 个是原来的后半段，应逆置 [0, n−p−1] 和 [n−p, n−1]。只改前三处时结果是 3 4 5 6 7 8 1 2（左移了 2 位，不是 3 位）。
5. 小问题：数组没当参数传，题目说存在 R 里，函数加上 `int R[]`。
6. （06:49 用户发来原卷照片后补）for 后面没加大括号，三句交换只有第一句在循环里，后两句只执行一次；函数名写成 reserve（保留），应为 reverse（逆置）；设计思想里区间写成 [0, n−p) 和 [n−p+1, n−1)，开闭混用，统一写闭区间 [0, n−p−1]、[n−p, n−1]。照片未公开。

**改后**（四处改动，结构不变）：

```c
void reverse(int R[], int i, int j){      // 逆置 R[i..j]
    for ( ; i < j; i++, j--){             // 改 1、2：不重新定义 i，条件 i<j
        int t = R[i]; R[i] = R[j]; R[j] = t;   // 改 3：临时变量交换
    }
}
void Converse(int R[], int n, int p){
    reverse(R, 0, n-1);       // 整体逆置
    reverse(R, 0, n-p-1);     // 改 4：前 n-p 个
    reverse(R, n-p, n-1);     // 改 4：后 p 个
}
```

gcc 核对：1–8 左移 3 位得 4 5 6 7 8 1 2 3；1–5 左移 1 位得 2 3 4 5 1，左移 4 位得 5 1 2 3 4。时间 O(n)，空间 O(1)。也可以先逆置 [0, p−1]、[p, n−1] 再整体逆置（王道答案的顺序），结果一样。
