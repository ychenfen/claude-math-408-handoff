## 08:18　走读页补成能教会人的

**问**：要能够教会我，现在是否有这个自信，不够的话补一下。

**答**：原来的走读只能“看它跑”，不够。补了四样，都在 [代码骨架走读](../../演示/数据结构/代码走读.html) 里：

1. **先懂思路**：每个例子在代码上面先给三句话，讲清这个骨架在干什么、为什么这么做。
2. **这一行为什么这样写**：关键行执行到时显示说明，内容取自手册各模板的“考场丢分点”（如 malloc 后先清零、p->adjvex 不是 p、先动 j 再动 i、L < R 配 R = mid）。
3. **先猜再看**：每个例子 1～3 个关键步骤会先停下来让你选（如“A[3] = 3 ≥ 3，R 变成几？”），选完给解释再继续执行；可关掉。
4. **错法对照**：7 个常见写错的版本照样逐行跑，结果都用 gcc 核对过：

| 错法 | 跑出来的结果 |
|---|---|
| 顺序表插入从前往后挪 | 1 3 5 6 6（8 丢了） |
| 逆置不存 r | 只剩 L → 1，2 3 丢了 |
| 层序漏写 last = rear | h = 1（实际 3） |
| DFS 不判 visit | 0 1 3 4 2 3 4（3、4 访问两次） |
| 孩子兄弟漏写 nextsibling | leaf = 1（实际 4） |
| 快排先动 i 再动 j | 9 1 2 4 7 6（9 跑到基准左边） |
| 二分 L <= R 配 R = mid | L = R = 2 后死循环 |

另加 **默写自测**：每个正确例子挖掉关键行，填完点“检查”逐行判对错，错的可看答案。建议顺序：思路 → 开着“先猜”播放一遍 → 看错法 → 默写自测 → 第二天闭卷手写拍照给我批。

## 08:21　骨架怎么背、怎么组合、要背哪些结构体

**问**：怎么背，后面怎么组合，还有哪些数据结构定义要背过的。

**答**：

**怎么背**：每次只背 1～2 个骨架。先看走读页的三句思路，再开着“先猜”播放一遍，看错法，然后做默写自测。第二天在白纸上闭卷写，拍照批改，错的行隔天重写，连续两天全对才算过。背的是“每一行为什么这样写”，不是死记字符。

**怎么组合**（手册第 2 章暴力五问，从 ① 往下问，第一个答“能”的就是做法）：
① 能枚举所有情况 → T1；② 能开数组记值或次数 → T2；③ 先排序或合并会变简单 → T3 或快排；④ 是链表 → T4 转成数组，再回到 ①②；⑤ 是树或图 → 遍历（T5 / T6 / T8 / T9），边走边算。
真题都是“一个遍历骨架 + 一个处理动作”：2024-41 是 T6 扫矩阵求入度 + T8 队列；2014 WPL 是 T5 先序 + 累加；2018 是 T2；2025 是 T1。59 题就是练这一步，套着练，不逐字背。

**要背的结构体**（手册第 4 章，零错）：顺序表 Sqlist、单链表 LNode / LinkList、二叉链表 BTNode / BiTree（lchild、rchild）、邻接矩阵 MGraph、邻接表 ANode / Vnode / Graph，P1 再加孩子兄弟 CSNode / CSTree。双亲表示法、孩子表示法只要看得懂。另背第 3.5 节固定写法：malloc 数组并清零、malloc 一个结点、交换三句、INT_MAX。考试给了结构体就一字不差照抄题目的。

## 09:01　`408-2010-41`　查找成功和失败的 ASL（重讲）＋ 打卡表里其他几类

## 14:48　`408-2010-42`　循环左移：在原代码上改错

**题**（2010 年 408 第 42 题；王道《数据结构》2.2 综合应用题 10）：设将 n（n > 1）个整数存放到一维数组 R 中。设计一个在时间和空间两方面都尽可能高效的算法。将 R 中保存的序列循环左移 p（0 < p < n）个位置，即将 R 中的数据由 (X0, X1, …, Xn−1) 变换为 (Xp, Xp+1, …, Xn−1, X0, X1, …, Xp−1)。要求：1）给出算法的基本设计思想。2）根据设计思想，采用 C 或 C++ 或 Java 语言描述算法，关键之处给出注释。3）说明你所设计算法的时间复杂度和空间复杂度。

**问**：10 年这个代码我错在哪里告诉我，我改改，在我基础上改为正确的。

**原代码**（按 10-10 记录转写，答题卡照片含姓名未公开）：

```c
void reverse(int i, int j){
    for (int i = 0; i < n; i++, j--){
        a[t] = a[i]; a[i] = a[j]; a[j] = a[t];
    }
}
reverse(0, n-1); reverse(0, n-p); reverse(n-p+1, n-1);
```

**错在哪**（gcc 跑过，n = 8、p = 3）：
1. for 里又写了 `int i = 0`：新定义了一个 i，参数 i 被盖掉，每次都从 0 开始。改成不重新定义。
2. 条件 `i < n`：换到一半后又换回去，整体逆置跑完数组原样不变（实测 1 2 3 4 5 6 7 8 没动）。改成 `i < j`。
3. 交换用 `a[t]` 当临时：t 没定义，而且借用数组里一格会覆盖数据。改成 `int t = a[i]; a[i] = a[j]; a[j] = t;`。
4. 两段分界差 1：整体逆置后前 n−p 个是原来的后半段，应逆置 [0, n−p−1] 和 [n−p, n−1]。只改前三处时结果是 3 4 5 6 7 8 1 2（左移了 2 位，不是 3 位）。
5. 小问题：数组没当参数传，题目说存在 R 里，函数加上 `int R[]`。

**改后**（四处改动，结构不变）：

```c
void reverse(int R[], int i, int j){      // 逆置 R[i..j]
    for ( ; i < j; i++, j--){             // 改 1、2：不重新定义 i，条件 i<j
        int t = R[i]; R[i] = R[j]; R[j] = t;   // 改 3：临时变量交换
    }
}
void Converse(int R[], int n, int p){
    reverse(R, 0, n-1);       // 整体逆置
    reverse(R, 0, n-p-1);     // 改 4：前 n-p 个
    reverse(R, n-p, n-1);     // 改 4：后 p 个
}
```

gcc 核对：1–8 左移 3 位得 4 5 6 7 8 1 2 3；1–5 左移 1 位得 2 3 4 5 1，左移 4 位得 5 1 2 3 4。时间 O(n)，空间 O(1)。也可以先逆置 [0, p−1]、[p, n−1] 再整体逆置（王道答案的顺序），结果一样。
