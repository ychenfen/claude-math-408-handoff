## 08:18　走读页补成能教会人的

**问**：要能够教会我，现在是否有这个自信，不够的话补一下。

**答**：原来的走读只能“看它跑”，不够。补了四样，都在 [代码骨架走读](../../演示/数据结构/代码走读.html) 里：

1. **先懂思路**：每个例子在代码上面先给三句话，讲清这个骨架在干什么、为什么这么做。
2. **这一行为什么这样写**：关键行执行到时显示说明，内容取自手册各模板的“考场丢分点”（如 malloc 后先清零、p->adjvex 不是 p、先动 j 再动 i、L < R 配 R = mid）。
3. **先猜再看**：每个例子 1～3 个关键步骤会先停下来让你选（如“A[3] = 3 ≥ 3，R 变成几？”），选完给解释再继续执行；可关掉。
4. **错法对照**：7 个常见写错的版本照样逐行跑，结果都用 gcc 核对过：

| 错法 | 跑出来的结果 |
|---|---|
| 顺序表插入从前往后挪 | 1 3 5 6 6（8 丢了） |
| 逆置不存 r | 只剩 L → 1，2 3 丢了 |
| 层序漏写 last = rear | h = 1（实际 3） |
| DFS 不判 visit | 0 1 3 4 2 3 4（3、4 访问两次） |
| 孩子兄弟漏写 nextsibling | leaf = 1（实际 4） |
| 快排先动 i 再动 j | 9 1 2 4 7 6（9 跑到基准左边） |
| 二分 L <= R 配 R = mid | L = R = 2 后死循环 |

另加 **默写自测**：每个正确例子挖掉关键行，填完点“检查”逐行判对错，错的可看答案。建议顺序：思路 → 开着“先猜”播放一遍 → 看错法 → 默写自测 → 第二天闭卷手写拍照给我批。

## 08:21　骨架怎么背、怎么组合、要背哪些结构体

**问**：怎么背，后面怎么组合，还有哪些数据结构定义要背过的。

**答**：

**怎么背**：每次只背 1～2 个骨架。先看走读页的三句思路，再开着“先猜”播放一遍，看错法，然后做默写自测。第二天在白纸上闭卷写，拍照批改，错的行隔天重写，连续两天全对才算过。背的是“每一行为什么这样写”，不是死记字符。

**怎么组合**（手册第 2 章暴力五问，从 ① 往下问，第一个答“能”的就是做法）：
① 能枚举所有情况 → T1；② 能开数组记值或次数 → T2；③ 先排序或合并会变简单 → T3 或快排；④ 是链表 → T4 转成数组，再回到 ①②；⑤ 是树或图 → 遍历（T5 / T6 / T8 / T9），边走边算。
真题都是“一个遍历骨架 + 一个处理动作”：2024-41 是 T6 扫矩阵求入度 + T8 队列；2014 WPL 是 T5 先序 + 累加；2018 是 T2；2025 是 T1。59 题就是练这一步，套着练，不逐字背。

**要背的结构体**（手册第 4 章，零错）：顺序表 Sqlist、单链表 LNode / LinkList、二叉链表 BTNode / BiTree（lchild、rchild）、邻接矩阵 MGraph、邻接表 ANode / Vnode / Graph，P1 再加孩子兄弟 CSNode / CSTree。双亲表示法、孩子表示法只要看得懂。另背第 3.5 节固定写法：malloc 数组并清零、malloc 一个结点、交换三句、INT_MAX。考试给了结构体就一字不差照抄题目的。

## 08:47　结构体也做成走读

**问**：结构体也教教我。

**答**：在 [代码骨架走读](../../演示/数据结构/代码走读.html#sq) 最前面加了“结构体”一栏，手册第 4 章 6 个结构体逐行讲，每加一个字段，右边的结构体方框就多一格。定义完再演示怎么用：

| 结构体 | 讲什么 | 先猜题 |
|---|---|---|
| 顺序表 Sqlist | data 数组 + length；变量用 .，指针用 -> | 为什么要 length；q.length 还是 q->length |
| 单链表 LNode / LinkList | 标签 LNode 为什么不能省；LinkList ≡ LNode *；申请头结点、头插 | next 为什么写 struct LNode *；sizeof 写 LNode 还是 LinkList |
| 二叉链表 BTNode / BiTree | lchild、rchild；新结点孩子置空；挂孩子 | *lchild, rchild 写法错在哪；怎么把 B 挂成左孩子 |
| 邻接矩阵 MGraph | numVertices、VerticesList、Edge；行和是出度、列和是入度 | 出度看行还是列；入度看行还是列 |
| 邻接表 ANode / Vnode / Graph | 三层：边结点 → 顶点 → 图；走边表 | G.adjlist[0] 后面用 . 还是 ->；w = p->adjvex 是几 |
| 孩子兄弟 CSNode / CSTree | 把 A(B(E,F),C,D(G)) 一步步存进去 | C 挂在哪个指针上；C 是不是叶子 |

每个都能“默写自测”挖空定义行。6 个结构体用 gcc -std=c99 -Wall 编译并跑了页面上的用法，结果和页面一致（如 sizeof(LNode) = 16、sizeof(LinkList) = 8）。
