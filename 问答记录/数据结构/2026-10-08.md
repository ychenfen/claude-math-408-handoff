## 16:51　`408-2009-41`　贪心找最短路径的方法是否可行

**题**（原题，取自王道《数据结构》第 6 章综合题 08【2009 统考真题】，22:23 补）：带权图（权值非负，表示边连接的两顶点间的距离）的最短路径问题是找出从初始顶点到目标顶点之间的一条最短路径。假设从初始顶点到目标顶点之间存在路径，现有一种解决该问题的方法：

① 设最短路径初始时仅包含初始顶点，令当前顶点 u 为初始顶点。
② 选择离 u 最近且尚未在最短路径中的一个顶点 v，加入最短路径，修改当前顶点 u = v。
③ 重复步骤②，直到 u 是目标顶点时为止。

请问上述方法能否求得最短路径？若该方法可行，请证明；否则，请举例说明。

**作答**：答“不能，该方法是短视的”。反例：a–b 权 3，a–c 权 3，b–d 权 5，c–d 权 2；若先选 b，得 a→b→d=8，而最短为 a→c→d=5。

**批改**：估 8/10。结论和反例都对；但 a 的两条边都是 3，打平时先选谁不确定，换成 a–b=1、a–c=3 更干净。错因：表述。

**漏洞**：反例构造的标准不清楚：不知道反例要排除歧义（不能靠打平的边权让方法“可能”选错）。

**补法**：复盘时说清：好的反例要让该方法“必然”走错，并给出两条路径的长度对比。

**检验**（迁移题，不重做原题）：换成“每次选权最小的边扩展生成树（Prim）一定得最小生成树吗”，判断能否、为什么。

## 16:51　`408-2009-42`　带头结点单链表的倒数第 k 个结点

**题**（原题，取自王道《数据结构》第 2 章综合题 17【2009 统考真题】，22:23 补）：已知一个带有表头结点的单链表，结点结构为

| data | link |
| --- | --- |

假设该链表只给出了头指针 list。在不改变链表的前提下，请设计一个尽可能高效的算法，查找链表中倒数第 k 个位置上的结点（k 为正整数）。若查找成功，算法输出该结点的 data 域的值，并返回 1；否则，只返回 0。要求：

1）描述算法的基本设计思想。
2）描述算法的详细实现步骤。
3）根据设计思想和实现步骤，采用程序设计语言描述算法（使用 C、C++ 或 Java 语言实现），关键之处请给出简要注释。

**作答**：(1) 开新数组置 0，把链表逐个读进数组，逆置后直接输出下标 k−1 的元素。(2) 空。(3) 代码定义了数组和结点结构，但赋值写成 `B[i]=A[m]`，没有 `p=p->link` 遍历链表；逆置用 `swap(m,n-m)`，n 未定义且下标差 1。

**批改**：估 5/15。思路可行但不是最优，代码不能运行。错因：模板没掌握。

**正确要点**：双指针一遍扫描，时间 O(n)、空间 O(1)。p、q 都从 list->link 出发，q 先走，计数到 k 后 p 再跟着走；q 到 NULL 时计数小于 k 返回 0，否则输出 p->data 并返回 1。官方标准：一遍扫描正确满分 15；两遍扫描（先求表长）最高 10。

**漏洞**：不只是没背双指针。代码里没有 p=p->link，说明“用指针遍历链表、边走边计数”这个最基本的操作还写不出来，所以只能退回到数组。

**补法**：先补链表遍历的基本写法：求表长、找第 i 个结点、找最后一个结点，三段代码都能闭卷写对。再理解“两个指针保持固定距离”为什么能一遍定位倒数位置。

**检验**（迁移题，不重做原题）：不考原题，换问法：找单链表的中间结点（快慢指针），或判断链表有没有环。

## 22:09　`408-2009-42`　怎么写（直接讲解法）

**问**：42怎么写

**答**：按手册 T4「先求长度」给暴力版（两遍扫描，官方标准最高 10 分），再给双指针一遍扫描（满分 15）。两段代码都用 gcc 编译，测试 5 结点链表 k=1、2、5、6 和空表，结果正确（k=6、空表返回 0）。

暴力版（T4）：

```c
typedef struct LNode{
    int data;
    struct LNode *link;          // 指针域：指向下一个结点
} LNode, *LinkList;

int Search_k(LinkList list, int k){
    int n = 0;
    LNode *p = list->link;       // 第一遍：求表长
    while (p != NULL){
        n++;
        p = p->link;
    }
    if (k < 1 || k > n) return 0;   // k 超出表长：查找失败
    p = list->link;              // 第二遍：走到正数第 n-k+1 个
    for (int i = 1; i < n - k + 1; i++)
        p = p->link;
    printf("%d", p->data);
    return 1;
}
```

复杂度：时间 O(n)（两遍），空间 O(1)。

双指针版（一遍）：q 先走 k 步，之后 p、q 一起走；q 到 NULL 时 p 就是倒数第 k 个。

```c
int Search_k(LinkList list, int k){
    LNode *p = list->link, *q = list->link;
    int count = 0;
    while (q != NULL){
        if (count < k) count++;  // 前 k 步只走 q
        else p = p->link;        // 之后 p 跟着走
        q = q->link;
    }
    if (count < k) return 0;     // 表长不足 k
    printf("%d", p->data);
    return 1;
}
```

对照原卷的三处漏洞：link 必须是 `struct LNode *`；遍历靠 `p = p->link`；失败是 `return 0`，不是打印 0。
