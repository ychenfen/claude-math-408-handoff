## 17:24　408-2011 整卷选择题错题（3、4、7）

**作答**：独立整卷作答，用户自己对答案并用红笔订正。3 选 A（应 B），4 选 A（应 C），7 选 B（应 A）。

**正确要点**：3 入队 rear 先加 1 再存，第一个元素落在 A[0]，所以 rear 初值 n−1、front 为 0。4 完全二叉树 768 个结点，偶数时 n₁ = 1，n₀ = ⌈768/2⌉ = 384。7 A 序列在 91 处向左走，之后都应小于 91，94 不可能。

**漏洞**：3 没看清“rear 指向队尾元素”和“先移后存”的组合；4 只列了 n = n₀ + n₁ + n₂，没用完全二叉树 n₁ 只能是 0 或 1；7 没逐步维护“当前上下界”。

**补法**：查找路径题逐个数维护区间：往左走就把上界改成当前值，往右走改下界，后面的数越界即不可能。完全二叉树叶子直接记 n₀ = ⌈n/2⌉。

**检验**（迁移题，不重做原题）：(a) 完全二叉树 1001 个结点、1000 个结点的叶子数？(b) 序列 50、20、40、30、45 能否是二叉排序树的查找路径？

## 17:24　`408-2011-42`　两个升序序列的中位数

**作答**：思想写“合并成新数组，取第 ⌈L/2⌉ 个”，代码用归并：两个 if 都用严格小于；剩余段写成 while (k < A.length)；返回 C.data[k/2 − 1]。复杂度写时间 O(n)、空间 O(n)。

**批改**：估 8/15。思想、复杂度、返回下标都对；非最优解最高约 10 分，再扣两处代码漏洞。错因：模板没掌握。

**漏洞**：A[i] 等于 B[j] 时两个分支都不执行，循环卡死；第一个剩余段的循环变量写错。另外不必真合并，数到第 L 个就停，空间可降到 O(1)。

**补法**：归并模板固定写成 if (A[i] <= B[j]) … else …，用 else 保证每轮一定前进一步；只需第 k 小时，用计数代替新数组。

**检验**（迁移题，不重做原题）：写 int midOf2(int A[], int B[], int n)，空间 O(1)，可能有相等元素；用 A = {2, 2, 7}、B = {2, 5, 9} 手推结果（应为 2）。

## 19:40　`59题-链表1`　带头结点单链表就地逆置（头插法）

**题**（原题，取自《408代码重点59题（必背）》单链表第 1 题）：试编写算法将带头结点的单链表就地逆置，即不需要借助辅助空间，保证空间复杂度为 O(1)。单链表默认结构体：`typedef struct LNode{ int data; struct LNode *next; } LNode, *LinkList;`

**问**：59 题链表的第一题。

**作答**：本条无作答。

**答**：
- 网站已有：`演示/数据结构/代码走读.html#t7c`（头插法就地逆置），另有错法 `#t7cx`（逆置不存 r）。
- 思路：把头结点断开当作空链，把原链结点逐个拆下，头插到 L 后面。
- 代码（同 PDF）：p = L->next; L->next = NULL; 循环 { r = p->next; p->next = L->next; L->next = p; p = r; }。
- 手跑 L → 1 → 2 → 3，依次得 L → 1、L → 2 → 1、L → 3 → 2 → 1。
- 易错点：
  - r 先存后继；
  - 头插两句不能对调；
  - 循环前要 L->next = NULL，否则第一个结点的 next 指回自己，成环。
- 时间 O(n)，空间 O(1)。
- 布置：闭卷写一遍。

**核对依据**：对照 PDF 原代码；代码走读页 t7c 已用 gcc 核对。

**来源**：408代码重点59题（必背）.pdf 第 10 页，单链表第 1 题。

## 19:44　`59题-链表2`　最小值结点：奇数与后继交换，偶数删后继

**题**（原题，取自《408代码重点59题（必背）》单链表第 2 题）：设有一个由正整数组成的无序单链表，编写程序实现以下功能：1、找出最小值结点（唯一）；2、若该数值是奇数，将其与后继结点交换（注意不是数值交换）；3、若该数值是偶数，则将其后继结点删除。

**问**：第二题。

**作答**：本条无作答。

**答**：
- 网站暂无此题。
- 思路：删、换结点都要改前驱，所以 pos 记最小结点的前驱（p、pos 从头结点出发，比较 p->next->data < pos->next->data）。
- 最小是最后一个结点时返回 false。
- u = pos->next，r = u->next，先 u->next = r->next 摘下 r：
  - 偶数：free(r)；
  - 奇数：r->next = u; pos->next = r。
- PDF 写 pos->next->data % 2，与 u->data 等价。
- 时间 O(n)，空间 O(1)。

**核对依据**：gcc -std=c99 -Wall 跑 PDF 代码。5 3 8 6 → 5 8 3 6；5 4 8 6 → 5 4 6；5 8 3 → false；3 9 → 9 3。

**来源**：408代码重点59题（必背）.pdf 第 10 页，单链表第 2 题。
