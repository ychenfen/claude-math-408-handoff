## 14:32　`59题-顺序表11`　三个递增序列的共同元素（三指针）

**题**（原题，取自《408代码重点59题（必背）》顺序表第 11 题；用户只说“59题里面11题”，按目录顺序默认为顺序表 11）：三个序列 A, B, C 长度均为 n，且均为无重复元素的递增序列，设计一个尽可能高效的算法，输出三个序列中共同存在的所有元素。

**问**：59 题里面 11 题。

**作答**：本条无作答。

**答**：
- 模板：T3 有序合并的三指针版，与 59 题顺序表 12（2020 三元组最小距离）同骨架。
- 思路：i、j、k 指向三序列开头；三数相等就输出并同时后移；否则比三数最大值小的指针后移；任一序列走完结束。时间 O(n)，空间 O(1)。暴力解三重循环 O(n³)。
- PDF 代码的 bug：fmax 用严格大于，两数并列最大（如 5、5、4）时返回 c = 4（最小值），三个指针都不动，死循环。gcc 实测 A = 1 3 5 7 9、B = 2 3 5 8 9、C = 3 4 5 6 9：原代码输出 3 后卡死（正确为 3 5 9）；A = 2 4、B = 2 4、C = 1 4 也卡死。
- 改法：只改 fmax 为 `if (a >= b && a >= c) return a; else if (b >= c) return b; else return c;`，两组例子分别输出 3 5 9、4，随机三组与三重循环暴力对拍一致。

**核对依据**：gcc -std=c99 -Wall 编译运行 PDF 原代码与改后代码。

**来源**：408代码重点59题（必背）.pdf 第 1–2 页目录、第 7 页顺序表第 11 题。

## 14:38　`59题-顺序表11`　讲解与走读页

**题**：同上条（三个长度均为 n 的无重复递增序列 A、B、C，输出三者共同存在的所有元素；《408代码重点59题（必背）》顺序表第 11 题）。

**问**：讲讲这个，我们网址有这个题吗。

**作答**：本条无作答。

**答**：
- 网站原来没有这道题。已在代码走读 T3 下加两个例子：「三个递增序列的共同元素（59 题顺序表 11）」（链接 `演示/数据结构/代码走读.html#t3c`）和「错法：fmax 用严格大于」（`#t3cx`）。
- 正确版用 A = 1 3 5 7 9、B = 2 3 5 8 9、C = 3 4 5 6 9 逐行跑，输出 3 5 9；中间两次停下让猜：(1, 2, 3) 时动哪些指针（i 和 j），(5, 5, 4) 时 fmax 返回几（5）。
- 错法版跑同一组数据，到 (5, 5, 4) 时原 fmax 返回 4，三个指针都不动，演示停在死循环处，只输出了 3。
- 讲法：三个数相等就输出并一起后移；不等就求最大值，比最大值小的数不可能是共同元素，它的指针后移（三个并列的 if，不是 else if）；任一序列走完结束。每轮至少一个指针后移，时间 O(n)，空间 O(1)。

**核对依据**：页面逐步结果与 14:32 条 gcc 实测输出一致；Playwright 在 1400px、390px 下逐步点完两个例子，无脚本错误，「下一步」按钮位置不变。
