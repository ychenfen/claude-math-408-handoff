## 14:32　`59题-顺序表11`　三个递增序列的共同元素（三指针）

**题**（原题，取自《408代码重点59题（必背）》顺序表第 11 题；用户只说“59题里面11题”，按目录顺序默认为顺序表 11）：三个序列 A, B, C 长度均为 n，且均为无重复元素的递增序列，设计一个尽可能高效的算法，输出三个序列中共同存在的所有元素。

**问**：59 题里面 11 题。

**作答**：本条无作答。

**答**：
- 模板：T3 有序合并的三指针版，与 59 题顺序表 12（2020 三元组最小距离）同骨架。
- 思路：i、j、k 指向三序列开头；三数相等就输出并同时后移；否则比三数最大值小的指针后移；任一序列走完结束。时间 O(n)，空间 O(1)。暴力解三重循环 O(n³)。
- PDF 代码的 bug：fmax 用严格大于，两数并列最大（如 5、5、4）时返回 c = 4（最小值），三个指针都不动，死循环。gcc 实测 A = 1 3 5 7 9、B = 2 3 5 8 9、C = 3 4 5 6 9：原代码输出 3 后卡死（正确为 3 5 9）；A = 2 4、B = 2 4、C = 1 4 也卡死。
- 改法：只改 fmax 为 `if (a >= b && a >= c) return a; else if (b >= c) return b; else return c;`，两组例子分别输出 3 5 9、4，随机三组与三重循环暴力对拍一致。

**核对依据**：gcc -std=c99 -Wall 编译运行 PDF 原代码与改后代码。

**来源**：408代码重点59题（必背）.pdf 第 1–2 页目录、第 7 页顺序表第 11 题。

## 14:52　`DS-20261015-void`　函数什么时候用 void

**题**：无原题。用户看完 59 题顺序表 11 的 `void samekey(...)` 后提问。

**问**：什么时候用 void。

**作答**：本条无作答。

**答**：
- 判断标准：调用完要不要把结果交回给调用者。不用交回就写 void，要交回就写结果类型并 return。
- 按题目动词判断：
  - 「输出、打印」用 void（samekey 边找边 printf）；
  - 「返回、求、判断」用对应类型（2018 最小未出现正整数、2020 三元组最小距离返回 int）；
  - 原地修改数组或链表一般用 void，因为传的是地址；
  - 递归用全局变量带结果时用 void（手册 WPL 先序写法），用后序返回值时要 int（树高）。

**核对依据**：助手讲解，例子取自 59 题顺序表 11、12 和代码走读 T5 的两个例子。

**来源**：408代码重点59题（必背）.pdf 第 7 页；`演示/数据结构/代码走读.html#t5a`、`#t5b`。

## 14:55　`59题-顺序表14`　交换用的 temp 在哪定义

**题**（原题，取自《408代码重点59题（必背）》顺序表第 14 题）：将数组中所有负数移动到数组最前端，所有非负数移动到数组的最后端。手册代码：
```c
void func(int A[], int n){
    int left = 0, right = n - 1;
    while(left < right){
        while(A[left] < 0 && left < right) left++;
        while(A[right] >= 0 && left < right) right--;
        if(left < right){
            int temp = A[left];
            A[left] = A[right];
            A[right] = temp;
        }
    }
}
```

**问**：14 题这个 temp 是临时定义的吗。

**作答**：本条无作答。

**答**：
- 是。`int temp` 定义在 if 的大括号里，是块内局部变量，出了大括号就失效。
- 作用是交换时先存住 A[left]，否则 `A[left] = A[right]` 之后原值就丢了。
- 也可以在函数开头写 `int temp;`，两种写法都对；C99 允许在块内随用随定义。

**核对依据**：对照 PDF 原代码。

**来源**：408代码重点59题（必背）.pdf 第 7 页，顺序表第 14 题。

## 15:21　`真题2025-乘积最大`　法二（从右往左维护最大、最小值）

**题**（原题，2025 年统考 42 题；取自《408代码重点59题（必背）》顺序表第 15 题）：两个长度均为 n 的一维整型数组 A[n]、res[n]，计算 A[i] 与 A[j]（0≤i≤j≤n−1）乘积的最大值，并将其保存到 res[i] 中。若 A[] = {1, 4, −9, 6}，则得到 res[] = {6, 24, 81, 36}。现给定数组 A，请设计时间和空间上尽可能高效的算法求 res 数组中各元素的值。

**问**：15 题第二种解法用会吗，暴力解会了。

**作答**：本条无作答。用户自述暴力解已会，没有附代码，不算作答证据。

**答**：
- 建议会：题目要求尽可能高效，法二 O(n) 是满分写法，比暴力只多十来行。
- 思路：res[i] 是 A[i] 乘 A[i..n−1] 中某个数。A[i] ≥ 0 乘右侧最大值，A[i] < 0 乘右侧最小值。从右往左扫，维护 max_val、min_val。
- 手跑 {1, 4, −9, 6} 得 36、81、24、6。
- 易错点：
  - 先更新 max/min 再算 res[i]，因为 j 可以等于 i；反过来 i=2 时会得 −54；
  - 初值取 A[n−1]，res[n−1] = A[n−1]²，循环从 n−2 开始。
- 时间 O(n)，空间 O(1)。

**核对依据**：对照 PDF 法二代码手跑题目样例。

**来源**：408代码重点59题（必背）.pdf 第 9 页，顺序表第 15 题法一、法二。

## 15:31　`408-2024-2`　同一表达式求前缀、中缀

**题**（原题，取自王道《数据结构》第 3 章选择题 19【2024 统考真题】）：与表达式 x + y*(z − u)/v 等价的后缀表达式是（ ）。A. x y z u − * v / +　B. x y z u − v / * +　C. + x / * y − z u v　D. + x * y / − z u v。答案：A。

**问**：24 年选择第二个这个是后缀，要是求其他的前缀中缀呢。

**作答**：本条无作答。

**答**：
- 同一棵表达式树：前序得前缀，中序得中缀，后序得后缀。
- 前缀：+ x / * y − z u v，正是选项 C；D 是选项 B 那棵错树的前缀式。
- 中缀：直接中序得 x + y * z − u / v，括号丢了；子树运算符优先级低于上层时要加括号，还原为 x + y*(z−u)/v。
- 加括号法：全加括号 (x + ((y * (z − u)) / v))，运算符挪到对应右括号后得后缀，挪到左括号前得前缀。选择题推荐此法。

**核对结果**：前缀式与 10-14 19:14 条所画树的前序遍历一致，由本助手推出；选项 C、D 的对应关系由前序遍历两棵树核对。

**来源**：王道《数据结构》Markdown 第 3 章选择题 19；[2026-10-14](2026-10-14.md) 19:13、19:14。
