## 19:13　`408-2024-2`　中缀转后缀：用树还是用栈

**题**（原题，取自王道《数据结构》第 3 章选择题 19【2024 统考真题】；统考题号按用户所说记为第 2 题）：与表达式 x + y*(z − u)/v 等价的后缀表达式是（ ）。
A. x y z u − * v / +　B. x y z u − v / * +　C. + x / * y − z u v　D. + x * y / − z u v
答案：A（王道答案页）。用户 10-12 整卷作答选 B（见 [2026-10-12](2026-10-12.md) 20:15）。

**问**：24 年选择第二个我以为要用到树呢，结构就是栈。

**作答**：本条无新作答，是对 10-12 作答的追问。

**答**：
- 树和栈都能做，两种方法结果一样。王道解析用的就是树：画表达式树（根 +，左 x；右子树根 /，/ 的左是 *（y 和 z−u），右是 v），后序遍历得 x y z u − * v / +。栈是手算法：运算符栈 + 输出序列。
- 选 B 不是方法选错，而是运算顺序错。B 还原回去是 x + y*((z−u)/v)，先除后乘。原式里 * 和 / 同级，从左往右，先算 y*(z−u)，再 /v。
- 用栈时，错就错在这一步：扫到 / 时栈顶是 *（同级），要先把 * 弹出再让 / 进栈；B 相当于让 / 压在 * 上面。规则：栈顶优先级大于或等于当前运算符就弹。
- 栈的全过程：x 出；+ 进；y 出；* 进（栈顶 + 比它低）；( 进；z 出；− 进；u 出；) 弹出 − 到左括号；/ 来了，弹出同级的 *，/ 进；v 出；结束依次弹 /、+。结果 x y z u − * v / +。
- 用树时，同级从左往右也决定树形：先算的 y*(z−u) 在下面，/ 在上面。

**漏洞**：同级运算符左结合（从左往右）的规则没落实，扫到同级运算符时没有先弹栈顶。

**补法**：中缀转后缀记一句“栈顶 ≥ 当前就弹，( 只在遇到 ) 时弹”；拿不准时把选项的后缀式还原成中缀对照。

**检验**（迁移题，不重做原题）：把 a − b + c * d / e − f 转成后缀表达式，写出扫到每个运算符时栈里有什么。

**核对结果**：A 与王道答案和解析一致；B 还原为 x + y*((z−u)/v) 由本助手推出。

**来源**：王道《数据结构》Markdown 第 3 章选择题 19 及解答（项目文件）。

## 19:24　`408-2024-6`　KMP 修正 next 数组的最大右滑距离

**题**（原题，取自王道《数据结构》第 4 章选择题 12【2024 统考真题】；统考题号按用户所说记为第 6 题）：KMP 算法使用修正后的 next 数组进行模式匹配，模式串为 S = 'aabaab'，当主串的某个字符与 S 的某个字符失配时，S 向右滑动的最长距离是（ ）。A. 5　B. 4　C. 3　D. 2。答案：A。用户 10-12 整卷作答选 D（见 [2026-10-12](2026-10-12.md) 20:15）。

**问**：24 年选择 6，怎么做的。

**作答**：本条无新作答，是对 10-12 作答的追问。

**答**（讲义法，下标从 0）：
- PM（各前缀最长相同前后缀）：a 0、aa 1、aab 0、aaba 1、aabaa 2、aabaab 3 → 0 1 0 1 2 3。
- next = PM 右移一位、首位补 −1：−1 0 1 0 1 2。
- nextval：第 j 位字符与第 next[j] 位字符相同就继续取那一位的 nextval，不同保留 next[j]：j1 a=a → −1；j2 b≠a → 1；j3 a=a → −1；j4 a=a（第 1 位）→ −1；j5 b=b（第 2 位）→ 1。nextval = −1 −1 1 −1 −1 1。
- 滑动距离 j − nextval[j]：1、2、1、4、5、4，最大 5（第 4 位、第 5 个字符 a 处失配）。
- 直观理解：第 4 位失配说明主串该字符不是 a，往回能退的第 1、0 位也是 a，必然再失配，所以整串滑过该字符，4 + 1 = 5。
- 与 1 起编号写法一致：nextval = 0 0 2 0 0 2，j = 5 时 5 − 0 = 5。

**漏洞**：只会求 next，不会求 nextval，也没有逐位列出 j − nextval[j] 再取最大。

**补法**：问“修正后／最长距离”时，固定三步：PM → next → nextval，再列一行滑动距离。

**检验**（迁移题，不重做原题）：模式串 abaabc，求 nextval 和失配时的最大滑动距离（1 起编号答案：nextval = 0 1 0 2 1 3，最大 4，在第 5 位）。

**核对结果**：A，与王道答案一致；nextval 与 2026-10-13 KMP 页的 Python 递推结果一致。

**来源**：王道《数据结构》Markdown 第 4 章选择题 12；罗素讲义第四章 改进 PM 法；[KMP 讲义法](../../演示/数据结构/KMP.html)。

## 19:26　`408-2024-6`　补：nextval 前两位（第 0、1 位）的规则

**题**：同上一条（2024 KMP，模式串 aabaab 的 nextval）。

**问**：01 求 nextval 的规则是什么（理解为第 0 位、第 1 位的 nextval 怎么定）。

**作答**：本条无作答。

**答**（下标从 0）：
- 第 0 位固定 −1：首字符就失配，无处可退，主串后移、模式串从头比。
- 第 1 位：next[1] 固定 0。若 P[1] = P[0]，失配字符 ≠ P[1] 也就 ≠ P[0]，退到第 0 位必再失配，nextval[1] = nextval[0] = −1；若 P[1] ≠ P[0]，nextval[1] = 0。例：aabaab → −1，abaabc → 0。
- 讲义说法：试到空串时，首字符与失配字符相同记 −1，不同记 0。
- 第 2 位起：P[j] 与 P[next[j]] 相同取 nextval[next[j]]，不同保留 next[j]。
- 下标从 1（王道）：各值加 1，第 1 位固定 0，第 2 位为 0（P2 = P1）或 1。

## 19:41　`408-2024-6`　追问：改进 PM 什么时候是 −1、什么时候是 0

**题**：同上（2024 选择第 6 题，模式串 aabaab 的 nextval）。

**问**：没有匹配不是 −1 嘛，有但是后面相同才是 0。

**作答**：本条无作答（用户提出的规则理解）。

**答**：这个理解不对。−1 和 0 都只在“试到空串”时出现，区别只看首字符与失配字符是否相同，与前面有没有相同前后缀无关。用 PPT 第 84 页 abababc 的表反驳：
- a(b)：无相同前后缀，首字符 a ≠ b → 0；ab(a)：无相同前后缀，a = a → −1。
- abab(a)：有 ab 但无效，空串 a = a → −1；ababa(b)：有 aba、a 但都无效，空串 a ≠ b → 0。

流程：最长 → 次长 → … 逐个试，紧邻字符 ≠ 失配字符就取该长度；都无效再试空串，首字符 ≠ 失配字符记 0，相同记 −1。理由：0 表示退到第 0 位再比，只有首字符可能对上时才有意义；首字符等于失配字符时必再失配，记 −1 直接跳过主串该字符。

**漏洞**：把 −1／0 的判据记成“有没有相同前后缀”，实际判据是空串那一步“首字符是否等于失配字符”。

**检验**：同上一条的 abaabc 迁移题，特别看 ab(a)、abaa(b) 两列。

**来源**：数据结构强化第一讲 PPT 第 82、84 页；罗素讲义第四章（“当最长相同前后缀为空串时，再看首个字符是否与上一轮失配字符相同，如果不相同，改进的PM就是0，否则就是-1”）。

**答**：
- 升序归并每次输出当前最小值，冠军是最小者，排除 A、C。
- 存段号不存关键字：输出后要从冠军所在段补入下一个记录并沿该路径重比；只存关键字还得逐段比首元素才知道来源（王道解析同此），排除 B。
- 01 讲义（罗素第八章 排序）5 路败者树图：叶子是 b0～b4 当前记录，内部结点 ls[1]～ls[4] 记 3、2、4、1（败者段号），ls[0] = 0（冠军是 b0，当前记录 1 最小）。
- 记两句：结点里存的全是段号（内部存败者、ls[0] 存冠军）；每补一个新记录只沿该段到根的路径重比，⌈log₂k⌉ 次。

**漏洞**：只记了“比大小”，没记清结点存的是段号；升序归并冠军是最小者也没对上。

**补法**：画 4 路小例子，每个结点同时写“段号（关键字）”，看输出后从哪一段补、沿哪条路径重比。

**检验**（迁移题，不重做原题）：4 路归并，各段当前首记录 b0:15、b1:8、b2:20、b3:11，画初始败者树，写出 ls[0]～ls[3] 存的段号；输出冠军后 b1 补入 30，重比哪条路径、ls[0] 变成几？
