## 15:51　`408-2024-18`　哪个事件不在 MMU 地址转换中检测

**题（原题，王道 27 版第 3 章所录 2024 统考真题）**：下列事件中，不是在 MMU 地址转换过程中检测的是（ ）。A. 访问越权　B. Cache 缺失　C. 页面缺失　D. TLB 缺失

**用户问题**：“18题”。10/12 整卷独立作答选 A，错误，应选 B（用户红笔订正）。

**讲解**（答案 B，与王道解析一致）
1. MMU 只负责虚拟地址 → 物理地址；Cache 在得到物理地址之后才查。
2. 访存顺序：虚拟地址 → 查 TLB（缺失 = D）→ 查页表项（有效位 0 = 缺页 C）→ 检查权限位（越权 = A）→ 得物理地址，MMU 结束 → 查 Cache（缺失 = B）→ 访主存。
3. 选 A 的原因推测：以为越权要到访问数据时才发现。实际权限位就在页表项和 TLB 表项里，MMU 拿到表项时就检查。
4. 记法：MMU 管翻译，翻译用到的 TLB、页表、权限位出问题都归它；Cache 管取数，用翻译完的物理地址。

**检验**：一次访存中，“TLB 命中、Cache 缺失、缺页”三者能否同时发生？为什么？（即 10/12 20:27 检验题 (c)）待用户作答。

## 15:55　`CO-存储层次-01`　Cache—主存层次和主存—辅存层次是不是一回事（接 408-2024-16）

**用户问题**：引用上一条讲解里的“Cache 层次要的是快，虚存层次怕的是访问外存太慢”，问“啥意思，这俩层次一样吗”。

**讲解**
1. 不一样，是存储金字塔里相邻的两对：Cache（SRAM，几 ns）—主存（DRAM，几十～上百 ns）为一对，目的是让主存“看起来”像 Cache 一样快；主存—辅存（磁盘，毫秒级）为另一对，即虚拟存储器，目的是让主存“看起来”像磁盘一样大。主存是两对共用的中间层。
2. 相同点：同一个套路，把常用的复制到上面更快更小的一层，靠局部性原理命中，都有命中、缺失、替换、写回。
3. 不同点来自缺失代价：Cache 缺失多等几十个周期，所以全硬件、映射可简单（直接、组相联）；缺页要几毫秒（几百万个周期），交给 OS 软件处理并切换进程，并且尽量少缺页：全相联、只用写回、页做大。
4. 一句话：同一套路用在两对存储器上，下面那对慢得多，所以宁可多花软件和表格功夫也要少缺一次。

## 16:00　`CO-存储层次-02`　Cache 比 CPU 快吗

**用户问题**：“cache比cpu块吗”（接上一条存储层次图，图中 CPU 画在 Cache 上方）。

**讲解**
1. 不是，Cache 比 CPU 慢。CPU 是“用数据的”，Cache、主存、磁盘是“放数据的”，快慢是这些存储层互相比。
2. 由近到远：寄存器（CPU 内部，1 个周期内）→ Cache（L1 约 1～几个周期，L2/L3 十几到几十个周期）→ 主存（上百个周期）→ 磁盘（毫秒级，几百万个周期）。周期数是常见数量级，做题以题目给的为准。
3. Cache 的作用是比主存快得多、离 CPU 近，让 CPU 少等主存，不是比 CPU 快。
