## 闭卷自测

以下是针对漏洞的迁移题，不是原题；数字由助手改编并算过。

### 自测：数据结构｜邻接矩阵上判断有无拓扑序列（2024-41 迁移）

**题干**：图用 2024-41 的 MGraph（邻接矩阵）存储。写 int hasTopo(MGraph G)：G 存在拓扑序列（无环）返回 1，否则返回 0。再说一句：要改成判断“拓扑序列唯一”，代码哪里加一行？

**参考要点**：
```c
int hasTopo(MGraph G){
    int n = G.numVertices, in[MAXV] = {0}, st[MAXV], top = 0, cnt = 0;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            if (G.Edge[i][j]) in[j]++;          // 列和就是入度
    for (int i = 0; i < n; i++)
        if (in[i] == 0) st[top++] = i;
    while (top > 0) {
        int v = st[--top]; cnt++;
        for (int j = 0; j < n; j++)
            if (G.Edge[v][j] && --in[j] == 0) st[top++] = j;
    }
    return cnt == n;                             // 全部输出才无环
}
```
判断唯一：在 while 循环开头加 `if (top > 1) return 0;`，即任一步有两个以上入度为 0 的顶点就不唯一。

### 自测：数据结构｜nextval 与最大右滑距离（2024-06 迁移）

**题干**：模式串 T = "abaabc"，用修正后的 nextval 匹配。写出 next 和 nextval；主串字符与 T 中字符失配时，T 向右滑动的最大距离是多少？

**参考要点**：next = 0 1 1 2 2 3，nextval = 0 1 0 2 1 3。失配在第 j 位时右滑 j − nextval[j]：1、1、3、2、4、3，最大 4（j = 5）。nextval = 0 时右滑 j 位，主串指针也后移。

### 自测：计算机组成原理｜截断、符号扩展与 MMU 检测项（2024-12、18 迁移）

**题干**：(a) int i = 40000; short s = i; int j = s; j 是多少？机器数是多少？(b) 访问越权、缺页、TLB 缺失、Cache 缺失，哪些在 MMU 地址转换过程中检测？

**参考要点**：(a) 40000 = 9C40H，截成 16 位最高位为 1，s = 40000 − 65536 = −25536；符号扩展后 j = FFFF9C40H = −25536。(b) 前三个在地址转换时检测；Cache 缺失要先得到物理地址，再查 Cache 才知道，不在 MMU 里。

### 自测：计算机组成原理｜数组元素地址与负数机器数（2024-44 迁移）

**题干**：int a[100] 首地址 0040 1000H，按字节编址，int 占 4B，补码表示。a[25] 的地址是多少？若 a[25] = −300，它的机器数（十六进制）是多少？

**参考要点**：地址 = 0040 1000H + 25 × 4 = 0040 1000H + 64H = 0040 1064H。300 = 12CH，−300 的补码 = 1 0000 0000H − 12CH = FFFF FED4H。

### 自测：操作系统｜时间片轮转周转时间与 CSCAN 移动距离（2024-30、32 迁移）

**题干**：(a) 时间片 4ms，8 个进程同时就绪，进程 P 排在队尾，P 需要 18ms，其余进程都至少需要 20ms，不计开销，P 的周转时间？(b) 磁道 0～199，磁头在 100 号、向增大方向移动，CSCAN，请求 150、30、199、0、60、120，磁头共移动多少？

**参考要点**：(a) P 要 5 个时间片（最后一片 2ms）。前 4 轮 4 × 8 × 4 = 128ms；第 5 轮前面 7 个进程各 4ms 共 28ms，P 再运行 2ms，共 158ms。(b) 100→120→150→199 走 99，回到 0 走 199，0→30→60 走 60，共 358。

### 自测：操作系统｜同步加互斥的 P、V 位置（2024-46 迁移）

**题干**：进程 P1 执行 A1、A2，进程 P2 执行 B1、B2。要求 A1 完成后 B1 才能开始；A2 和 B2 都要访问同一个共享缓冲区，必须互斥。写出信号量定义和两个进程的代码。

**参考要点**：semaphore s = 0, mutex = 1;
P1：A1; signal(s); wait(mutex); A2; signal(mutex);
P2：wait(s); B1; wait(mutex); B2; signal(mutex);
互斥一定是 wait 在临界区前、signal 在后；同步是“先做的一方 signal，后做的一方 wait”。

### 自测：计算机网络｜NAV、HTTP 的 RTT 数与 TCP 释放时间（2024-36、38、40 迁移）

**题干**：(a) SIFS = 10μs，CTS 和 ACK 帧发送各 4μs，数据帧 1500B、链路 24Mb/s，忽略传播时延。RTS 和 CTS 里的 NAV 各是多少？(b) HTTP/1.0 非持久、不并行，网页引用 5 张同站图片，共需几个 RTT？换成持久非流水和持久流水呢？(c) 发送 1000B（MSS = 1000B），RTT = 20ms，MSL = 10s，从请求建立连接到主动关闭方进入 CLOSED 至少多久？

**参考要点**：(a) 数据帧 12000bit ÷ 24Mb/s = 500μs。CTS 的 NAV = 10 + 500 + 10 + 4 = 524μs；RTS 的 NAV 再加 SIFS + CTS = 538μs。(b) 非持久 6 × 2 = 12；持久非流水 1 + 6 = 7；持久流水 1 + 1 + 1 = 3。(c) 握手 1 RTT、数据 1 RTT、释放 1 RTT，共 60ms，加 TIME_WAIT 2MSL = 20s，共 20.06s。
