# 考试记录：整卷模拟与错题

每做完一套整卷（408 真题、数二真题、模拟卷），在本目录新建一个文件。网页「六科总览」会显示成绩走势和丢分分布，错题的闭卷自测会进入对应科目的「闭卷自测」和「睡前复习」。

## 文件名

`YYYY-MM-DD_科目_试卷.md`，例如 `2026-10-08_408_2009真题.md`。科目写 `408` 或 `数学二`。日期按北京时间，是做卷的日期。

## 必须有的小节

1. `## 成绩`：一行表格，列为 日期｜科目｜试卷｜用时｜选择｜大题｜总分｜满分。总分必须等于选择加大题；没记用时写“未记”。下面用列表写估分方式：自己对答案、助手估分，还是老师批改。
2. `## 逐题丢分`：每道丢分的题一行，列为 题号｜题型｜科目｜得分｜满分｜错因｜要点。
   - 题型：选择／填空／大题。
   - 科目用六科名：高等数学、线性代数、数据结构、计算机组成原理、操作系统、计算机网络。
   - 错因只能从这些里选，方便统计：概念不清、模板没掌握、审题、计算漏步、同步顺序、没做完、知识点不会、表述、粗心、待补。
3. `## 闭卷自测`：为值得反复练的错题写自测卡。标题写 `### 自测：科目｜题意（试卷-题号）`，科目必须是六科名之一，这样才能进对应科目的复习队列。卡片格式和每日复盘一样：先 `**题干**：`，再 `**参考要点**：`。
4. `## 下次先做`：最多 3 项，用 `- [ ]`。
5. `## 来源与边界`：说明成绩怎么来的、哪些内容没核实。作答原图有个人信息时不要公开。

## 检查

`python3 scripts/exams.py` 汇总全部整卷并检查格式；`python3 scripts/build_site.py` 会把考试记录写进网页数据。

考试记录只记成绩和丢分，不改变各科「题目状态」。要追踪某道错题的重做情况，请由该科助手写进本科每日复盘。
