## 知识点与适用条件

- **波特率与数据率**：数据率 = 波特率 × log₂M，M 是码元种数。4 相位时 M = 4，每码元 2 bit；16-QAM 时 M = 16，每码元 4 bit。已知数据率求波特率要除，不是乘。
- **CSMA/CD 与 CSMA/CA**：
  - CSMA/CD：用于有线、半双工共享介质，边发边检测冲突；检测到冲突就停发并退避；不对正确收到的帧回确认。
  - CSMA/CA（802.11）：用于无线，无法边发边检测冲突，所以靠帧间间隔和退避来避免冲突；接收方正确收到数据帧后要回 ACK。
- **子网里的特殊地址**：子网题先写出网络地址（主机号全 0）和广播地址（主机号全 1），剩下的才是可分配的主机地址。目的地址是广播地址时，子网内所有主机都能收到。
- **在以太网帧字节里找 IP 字段**：
  - 先跳过以太网首部 14B（目的 MAC 6B、源 MAC 6B、类型 2B）。
  - 再按 IP 首部数：第 9 字节是协议，第 13～16 字节是源 IP，第 17～20 字节是目的 IP。
- **ARP 请求与数据帧的目的 MAC**：
  - 主机发往外网时，目的 IP 不在本子网，要先用 ARP 解析默认网关的 MAC。
  - ARP 请求帧是广播，目的 MAC 为 FF-FF-FF-FF-FF-FF。
  - 拿到网关 MAC 后，数据帧的目的 MAC 写网关的 MAC，目的 IP 仍是外网服务器。
- **路由器和 NAT 改哪些字段**：普通路由器转发时，TTL 减 1，首部校验和重新计算。NAT 路由器还要改源 IP 地址（NAPT 还改源端口），运输层校验和也随之重算。

## 闭卷自测

### 自测：迁移｜已知数据率求波特率

**题干**：某链路采用 16-QAM 调制，数据传输速率为 4800bps。该链路的波特率是多少？若改用 4 相位调制、波特率保持不变，数据率是多少？本题改编自 `408-2011-34`，不是原真题。

**参考要点**：
- 16-QAM 每码元 log₂16 = 4 bit，波特率 = 4800 ÷ 4 = 1200 波特。
- 4 相位每码元 2 bit，数据率 = 1200 × 2 = 2400bps。
- 易错：已知数据率求波特率时乘了 log₂M。

### 自测：迁移｜目的地址是子网广播地址时谁能收到

**题干**：某子网为 10.0.0.8/29。一个分组的目的 IP 地址是 10.0.0.15，该子网中最多有几台主机能收到这个分组？写出这个子网的网络地址、广播地址和可分配的主机地址范围。本题改编自 `408-2011-38`，不是原真题。

**参考要点**：
- /29 的块大小为 8，10.0.0.8/29 包含 .8～.15。
- 网络地址 10.0.0.8，广播地址 10.0.0.15，可分配主机 .9～.14，共 6 台。
- 目的地址是广播地址，所以最多 6 台主机都能收到。

### 自测：CSMA/CD 与 CSMA/CA 对比

**题干**：从适用的网络、能否边发送边检测冲突、发生冲突后怎样处理、接收方是否对正确收到的数据帧回确认四个方面，对比 CSMA/CD 和 CSMA/CA。本题来自 `408-2011-36` 的错因整理，不是原真题。

**参考要点**：
- 适用网络：CSMA/CD 用于有线、半双工共享介质的以太网；CSMA/CA 用于 802.11 无线局域网。
- 冲突检测：CSMA/CD 边发边检测；CSMA/CA 无法边发边检测，靠帧间间隔和随机退避来避免。
- 冲突处理：CSMA/CD 检测到冲突后立即停止发送，发干扰信号，按二进制指数退避重发；CSMA/CA 发生冲突时收不到 ACK，超时后退避重传。
- 确认：CSMA/CD 不确认；CSMA/CA 接收方正确收到后回 ACK。

### 自测：迁移｜ARP 请求帧和数据帧的目的 MAC

**题干**：主机 H（IP 192.168.0.8）要向外网服务器 S（IP 64.170.98.32）发送一个 IP 分组。H 的默认网关是路由器 R 的内网接口（IP 192.168.0.1，MAC 00-21-27-21-51-ee），H 的 ARP 缓存为空。(1) H 发出的 ARP 请求帧中，目的 MAC 地址和要解析的目标 IP 地址各是什么？(2) H 随后发出的以太网数据帧中，目的 MAC 地址和 IP 分组的目的 IP 地址各是什么？本题改编自 `408-2011-47`，不是原题题面。

**参考要点**：
- (1) ARP 请求帧的目的 MAC 是广播地址 FF-FF-FF-FF-FF-FF，要解析的目标 IP 是网关 192.168.0.1，不是 S 的 IP。
- (2) 数据帧的目的 MAC 是网关的 00-21-27-21-51-ee，IP 分组的目的 IP 仍是 64.170.98.32。
- 规律：MAC 地址只在一段链路内有效，逐跳改变；IP 地址端到端不变（经过 NAT 时除外）。

### 自测：迁移｜经过三台路由器后 IP 首部改了哪些字段

**题干**：内网主机发往外网服务器的一个 IP 分组，依次经过两台普通路由器和一台 NAT 路由器（NAT 路由器是最后一跳出内网的那台），途中不分片。到达服务器时，IP 首部中哪些字段被修改过？各改了几次？本题改编自 `408-2011-47` 第 (4) 问，不是原真题。

**参考要点**：
- TTL：每经过一台路由器减 1，共改 3 次。
- 首部校验和：每台路由器都要重新计算，共改 3 次。
- 源 IP 地址：只在 NAT 路由器处由内网地址改为公网地址，改 1 次（NAPT 还改源端口，运输层校验和随之重算）。
- 目的 IP 地址不变。
