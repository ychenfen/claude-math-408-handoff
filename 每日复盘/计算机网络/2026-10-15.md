## 知识点与适用条件

- **数字调制看缩写**：ASK（移幅键控）改变振幅，FSK（移频键控）改变频率，PSK（移相键控）改变相位。DPSK（差分移相键控）靠相邻码元的相位变化传递信息，可以和差分曼彻斯特编码对照着记。
- **802.11 的 NAV**：
  - RTS 里：SIFS + CTS + SIFS + DATA + SIFS + ACK。
  - CTS 里：SIFS + DATA + SIFS + ACK。
  - DATA 里：SIFS + ACK。
  - 都不含开头的 DIFS。控制帧长度：RTS 20B，CTS 14B，ACK 14B（依据讲解视频）。
- **TCP 建连到 CLOSED**：
  - 第三次握手可以携带数据，忽略发送时延时，带不带数据都不多花 RTT。
  - “时间最多”也不能理解成先等对方回 ACK 再发数据，那样等于四次握手。
  - 终点是主动关闭方进入 CLOSED，所以要加 2MSL。
- **HTTP 非持续连接**：每个对象新建一条连接，但下一条不用等上一条释放完，这仍然叫“不并行”。题目没给 MSS 时，不要凭空考虑拥塞窗口。
- **RIP 收敛时间**：启动时的第一次交换算第 0 秒，之后每过 30s 消息多传一跳。看离目的网络最远的路由器要隔几跳，就是几轮之后才收到。依据：讲解视频，教材页码待核实。
- **BGP 选路顺序**（讲解视频给的完整版）：
  1. 本地偏好 local preference 值高的优先。
  2. AS 跳数少的优先。
  3. 热土豆：在 AS 内离出口近的优先，每台路由器各自按 IGP 计算。
  4. BGP 标识符小的优先。BGP 标识符是 32 位，取路由器最大的 IP 地址，由 OPEN 报文交换。
  - 前一条分出胜负就停。王道只写了 ② 和 ③；题目说“无策略约束”，就从 ② 开始。
- **iBGP 通告规则补充**：从 iBGP 收到的路由，不能转给其他 iBGP 对等方，但可以经 eBGP 告诉别的 AS。经 eBGP 发出时，要把本 AS 加进 AS 路径，下一跳改为自己（这一条由助手推出，课件没有画出来）。

## 闭卷自测

### 自测：三种帧里的 NAV 各由哪几段组成

**题干**：802.11 无线局域网使用 RTS/CTS 机制，帧序列为 RTS → SIFS → CTS → SIFS → DATA → SIFS → ACK。分别写出 RTS 帧、CTS 帧、DATA 帧中的 NAV 由哪几段时间组成，并说明 RTS 里的 NAV 比 CTS 里的多哪两段。本题来自 07:57 讲解后的检验，不是原真题。

**参考要点**：
- RTS：SIFS + CTS + SIFS + DATA + SIFS + ACK。
- CTS：SIFS + DATA + SIFS + ACK。
- DATA：SIFS + ACK。
- RTS 比 CTS 多一个 SIFS 和一个 CTS。规律：都从本帧发完算到 ACK 发完，开头的 DIFS 不算。

### 自测：迁移｜本地偏好和 AS 跳数冲突时选哪条

**题干**：AS1 内有两条到 AS9 的 BGP 路由：经出口 R1 的本地偏好为 100，AS 路径经过 2 个 AS；经出口 R2 的本地偏好为 200，AS 路径经过 4 个 AS。AS1 内的路由器选哪个出口？为什么不比较 AS 跳数？本题来自 07:57 讲解后的检验，不是原真题。

**参考要点**：
- 选 R2。BGP 先比本地偏好，值高的优先；200 > 100，第一步已经分出胜负，就不再比后面的 AS 跳数。
- 只有题目说“无策略约束”（没有设本地偏好）时，才从 AS 跳数开始比。

### 自测：迁移｜同一个 AS 内两台路由器可以选不同出口吗

**题干**：AS1 内运行 RIP，两个出口路由器 Rx 和 Ry 都通告了到网络 N 的路由。经 Rx 的 AS 路径为 AS2 AS5，经 Ry 的 AS 路径为 AS3 AS5。路由器 Ra 到 Rx 要 3 跳、到 Ry 要 1 跳；路由器 Rb 到 Rx 要 1 跳、到 Ry 要 3 跳。(1) 无策略约束时，Ra 和 Rb 各选哪个出口？各用的是第几条规则？(2) 若管理员把经 Rx 的本地偏好设为 300、经 Ry 的设为 100，Ra 改选哪个？本题改编自 08:04 的检验，不是原真题。

**参考要点**：
- (1) 两条 AS 路径都经过 2 个 AS，打平；用第 ③ 条热土豆，各自选 AS 内离自己近的出口：Ra 选 Ry，Rb 选 Rx。同一个 AS 内的路由器可以选不同的出口。
- (2) 第 ① 条本地偏好先比，300 > 100，Ra 改选 Rx。

### 自测：迁移｜RIP 消息几秒后传到最远的路由器

**题干**：四台路由器 R1、R2、R3、R4 依次串联，网络 N 直接连在 R1 上。所有路由器同时启动并运行 RIP，启动时立即交换一次路由信息（记为第 0 秒），之后每 30s 交换一次。不考虑报文丢失和处理时延，R2、R3、R4 分别在第几秒得到到达 N 的路由？本题依据 07:57 记录的 2024-47(3) 讲解方法改编，不是原真题。

**参考要点**：
- 第 0 秒的交换中，R1 把 N 告诉 R2，所以 R2 在第 0 秒得到。
- 之后每 30s 多传一跳：R3 在第 30 秒得到，R4 在第 60 秒得到。
- 方法：看离目的网络最远的路由器隔几跳。审题时注意题目把哪一刻算作第 0 秒。
