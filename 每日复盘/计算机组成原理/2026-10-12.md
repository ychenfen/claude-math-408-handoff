## 知识点与适用条件

- **截断（长 → 短）**：只留低 n 位，按新类型重新解释。新最高位是 0，值就是低 n 位；是 1（有符号），值 = 低 n 位的无符号值 − 2ⁿ。原值在新类型范围内时截断不改值。
- **扩展（短 → 长）**：看**源类型**。有符号做符号扩展，无符号做零扩展，扩展不改值。short → int 的两步链：先截断可能改值，再扩展保持这个新值。
- **指令里的字段**：要参与有符号运算的偏移量、立即数做符号扩展；移位量是无符号的位数，只看格式表规定的几位（32 位机器 5 位）。
- **数组元素地址**：一维 &a[i] = 首地址 + i × 元素字节数；二维按行优先 &a[i][j] = 首地址 + (i × 列数 + j) × 元素字节数。
- **负数补码机器数**：n 位机器数 = 2ⁿ − |x|；十六进制快算：|x| 补满位数，逐位用 F 减，再加 1。自查：机器数 + |x| 正好进位成 1 后面全 0。
- **Cache 与虚存**：Cache 解决速度、全硬件、块几十字节、三种映射、写直达或写回；虚存解决容量、硬件 + OS、页 KB 级、全相联、只能写回。访存顺序：TLB → 页表（缺页则异常）→ 物理地址 → Cache → 主存。
- **浮点数精确表示整数**：看尾数有效位数，单精度 24 位（含隐藏位），|x| ≤ 2²⁴ 的整数都能精确表示；双精度 53 位。
- **中断两种优先级**：响应优先级是多个请求**同时**到来先响应谁，由硬件判优决定，软件改不了；处理优先级是正在服务时谁能**打断**谁，由屏蔽字决定。被屏蔽的请求不丢，等屏蔽解除再响应。

## 闭卷自测

### 自测：迁移｜无符号短整数赋给 int 和 short

**题干**：C 语言中 short 为 16 位、int 为 32 位，均用补码表示，unsigned short 为 16 位无符号数。执行：unsigned short us = 0xFF9C; int x = us; short s = us; int y = s; 求 x、y 的十进制值和 32 位机器数（十六进制）。再求：int i = −70000; short t = i; t 的值是多少？本题改编自 `408-2024-12`，不是原真题。

**参考要点**：
- x：源是无符号数，零扩展，x = 0000 FF9CH = 65436。
- s：位模式 FF9CH 按有符号读，最高位 1，值 = 65436 − 65536 = −100；y 由 s 符号扩展，y = FFFF FF9CH = −100。
- t：−70000 = FFFE EE90H，留低 16 位 EE90H = 61072，最高位 1，t = 61072 − 65536 = −4464。
- 扩展看源类型，截断看新最高位。

### 自测：迁移｜二维 short 数组的地址和负数机器数

**题干**：short b[50][20] 按行优先存放，首地址为 0040 2000H，按字节编址，short 占 2B，用补码表示。(a) &b[3][7] 是多少？(b) 若 b[3][7] = −1000，写出它的 16 位机器数；把它赋给 int 变量后，32 位机器数是多少？本题改编自 `408-2024-44`，不是原真题。

**参考要点**：
- (a) (3 × 20 + 7) × 2 = 134 = 86H，地址 0040 2086H。
- (b) 1000 = 03E8H，逐位用 F 减得 FC17H，加 1 得 FC18H；自查 FC18H + 03E8H = 1 0000H。
- 赋给 int 符号扩展：FFFF FC18H，值仍是 −1000。

### 自测：Cache 与虚存的三个为什么

**题干**：某计算机有 Cache—主存和主存—辅存（页式虚拟存储器）两个层次，带 TLB。回答：(a) 为什么虚存只能用写回，不用写直达？(b) 为什么虚存用全相联映射，Cache 却常用组相联？(c) 一次访存中，“TLB 命中、Cache 缺失、缺页”三件事能不能同时发生？为什么？本题为自编练习，接 `408-2024-16`、`408-2024-18`。

**参考要点**：
- (a) 辅存是磁盘，每次写都写到磁盘太慢，只能等页被换出时再写回。
- (b) 缺页代价极大，全相联让页可以放进任一页框、缺页率最低，查找靠页表而不是比较器；Cache 要硬件在几个周期内并行比较标记，全相联比较器太多，组相联是速度和命中率的折中。
- (c) 不能。TLB 里只放已在主存的页的表项，TLB 命中说明页在主存，不会缺页；TLB 命中、Cache 缺失可以同时出现。

### 自测：迁移｜用屏蔽字改处理优先级

**题干**：某计算机有 4 个中断源 L0、L1、L2、L3，硬件响应优先级为 L0 > L1 > L2 > L3。要使处理优先级变为 L1 > L3 > L0 > L2。(a) 写出每个中断服务程序的屏蔽字（按 L0 L1 L2 L3 的顺序，1 表示屏蔽）。(b) L0 和 L2 同时请求，先响应谁？L0 的服务程序执行中 L3 发出请求，L3 会不会打断 L0？本题改编自 `408-2024-21` 的考点，不是原真题。

**参考要点**：
- 每个服务程序屏蔽自己和处理优先级比自己低的源。
- L0：1 0 1 0；L1：1 1 1 1；L2：0 0 1 0；L3：1 0 1 1。
- (b) 同时请求按响应优先级，先响应 L0；L0 的屏蔽字对 L3 那一位是 0，L3 处理优先级比 L0 高，能打断 L0。
- 屏蔽字只改“谁能打断谁”，改不了同时请求时谁先被响应。

### 自测：迁移｜单精度能否精确表示 ±2³⁰ 以内的整数

**题干**：IEEE 754 单精度浮点数有 1 位符号、8 位阶码、23 位尾数（规格化数隐含最高位 1）。要精确表示 −2³⁰～+2³⁰ 之间的所有整数，用单精度 float 行不行？为什么？如果不行，int（32 位补码）和 double 哪个可以？本题改编自 `408-2024-14`（原题为 ±2²⁰ 和 ±2⁴⁰），不是原真题。

**参考要点**：
- 不行。单精度有效位 24 位，只能保证 |x| ≤ 2²⁴ 的整数都能精确表示；例如 2²⁴ + 1 就表示不了。
- int 范围 −2³¹～2³¹−1，能表示；double 有效位 53 位，也能。
- 判断方法：浮点数“能精确表示多大的整数”看尾数有效位，不看阶码范围。
