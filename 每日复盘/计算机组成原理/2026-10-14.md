## 知识点与适用条件

- **溢出的判断法分在 PPT 不同章节**（07:17 整理，页码为 PDF 页码）：
  - 定义：真值超出表示范围（第二章 p150–151）。
  - 一位符号位：两数同号、结果异号才溢出，异号相加不溢出（第二章 p153–157）。
  - 双符号位：01 正溢出、10 负溢出，高位符号位永远是真符号（第二章 p158–166）。
  - 进位判断：OF = Cn ⊕ Cn+1，Cn 是最高数值位向符号位的进位，Cn+1 是符号位向外的进位（第二章 p167–170，第四章 p70–84）。
  - 无符号加减：CF = sub ⊕ Cout（第二章 p171–178）。
  - 乘法：乘积放不进 n 位就溢出，硬件看 2n 位乘积的高 n+1 位是否全同（强化 1 p44–58）。
  - 左移：逻辑左移移出 1 就溢出；补码左移移出位与符号不同就溢出（强化 1 p41）。
  - 浮点：只看规格化后的阶码（第二章 p286–289，强化 1 p72–75）。
- **四个标志位**：
  - ZF：结果 n 位全 0 时为 1，只看留下的 n 位；有符号、无符号通用。
  - SF：就是结果最高位。不溢出时是真实符号；溢出时正好反了，真实符号 = SF ⊕ OF（即双符号位的高位）。只对有符号数有意义。
  - CF：加法 CF = Cout；减法实际算 A + (2ⁿ − B)，A ≥ B（无符号）才有进位，所以 CF = sub ⊕ Cout，CF = 1 表示借位。只对无符号数有意义，有符号数不看 CF。
  - OF：正 + 正时 Cn+1 恒为 0，Cn = 1 就溢出；负 + 负时 Cn+1 恒为 1，Cn = 0 就溢出；一正一负两者恒相等，不会溢出。只对有符号数有意义。
- **用 cmp（A − B）比大小**：有符号数 ZF = 0 且 SF = OF 为大于，SF ≠ OF 为小于；无符号数 ZF = 0 且 CF = 0 为大于，CF = 1 为小于（第四章 p83–84）。
- **“上溢、下溢”有两套说法**：定点补码有的页把比最小负数还小叫下溢；浮点数的下溢是绝对值太小、接近 0，一般按机器零处理，上溢才报溢出。

## 闭卷自测

### 自测：8 位加法的四个标志位

**题干**：8 位补码加法器计算 A + B，A = 70H，B = 50H。写出结果的机器数，最高数值位向符号位的进位 Cn、符号位向外的进位 Cn+1（即 Cout），以及 ZF、SF、CF、OF；按有符号数解释，真实结果是正还是负、有没有溢出？按无符号数解释，有没有溢出？本题为自编练习，检验今天整理的标志位。

**参考要点**：
- 70H + 50H = C0H。低 7 位 111 0000 + 101 0000 向符号位进位，Cn = 1；符号位 0 + 0 + 1 = 1，不向外进位，Cn+1 = 0。
- ZF = 0，SF = 1，CF = Cout = 0，OF = Cn ⊕ Cn+1 = 1。
- 有符号：112 + 80 = 192 > 127，溢出；真实符号 = SF ⊕ OF = 0，是正数，SF = 1 说反了。
- 无符号：112 + 80 = 192 ≤ 255，CF = 0，不溢出。
- 可视化：[溢出与符号判断](../../演示/计算机组成原理/溢出与符号判断.html)

### 自测：迁移｜减法后有符号、无符号比大小结论相反

**题干**：8 位机器执行 cmp A, B（即计算 A − B，只设标志位），A = 80H，B = 01H。加法器实际算的是 A + B 的反码 + 1。写出加法器的结果、Cout、Cn、Cn+1，以及 ZF、SF、CF、OF。按有符号数和无符号数分别判断 A 与 B 的大小，并说明依据的标志位。本题为迁移改编，由加法换成减法，不是原真题。

**参考要点**：
- 80H + FEH + 1 = 17FH，结果 7FH，Cout = 1。低 7 位 000 0000 + 111 1110 + 1 = 111 1111，不向符号位进位，Cn = 0；符号位 1 + 1 + 0 产生进位，Cn+1 = 1。
- ZF = 0，SF = 0，CF = sub ⊕ Cout = 1 ⊕ 1 = 0，OF = 0 ⊕ 1 = 1。
- 有符号：−128 − 1 = −129 溢出；SF ≠ OF，A < B（−128 < 1）。
- 无符号：CF = 0 且 ZF = 0，A > B（128 > 1）。
- 同一组标志位，有符号看 SF 与 OF，无符号看 CF。
- 可视化：[溢出与符号判断](../../演示/计算机组成原理/溢出与符号判断.html)

### 自测：迁移｜负数乘正数是否溢出

**题干**：x、y 是 8 位补码整数，x = 0CH，y = F6H，乘积存入 8 位寄存器。写出 x、y 的真值和真实乘积，判断是否溢出；再写出 16 位乘积的机器数，用“高 n+1 位是否全同”验证你的判断。本题改编自 `408-2010-13`（原题是负×负），不是原真题。

**参考要点**：
- x = 12，y = −10，乘积 −120，在 −128～+127 内，不溢出。
- 16 位乘积：120 = 0078H，取反加 1 得 FF88H = 1111 1111 1000 1000。
- 高 9 位 1111 1111 1 全为 1，不溢出，与真值判断一致。
- 乘法不能用“符号变没变”判断，要看真实乘积或高 n+1 位。
- 可视化：[溢出与符号判断](../../演示/计算机组成原理/溢出与符号判断.html)

### 自测：迁移｜阶码双符号位说明了什么

**题干**：某浮点数格式的阶码用 5 位补码表示，含 2 位符号位（双符号位），数值范围 −8～+7。三次浮点运算规格化之后，阶码分别为 01 000、10 111、11 000。各自代表多少？哪一个是浮点上溢、哪一个是浮点下溢、哪一个正常？上溢和下溢通常怎么处理？本题改编自 `408-2009-13` 的判溢出一步，不是原真题。

**参考要点**：
- 01 000：+8，超出 +7，阶码正溢出 → 浮点数上溢（尾数正为正上溢、负为负上溢），要报溢出、做异常处理。
- 10 111：−9，低于 −8，阶码负溢出 → 浮点数下溢（绝对值太小），一般按机器零处理，不报错。
- 11 000：−8，在范围内，正常。
- 尾数的 01、10 只说明要右规；判浮点溢出只看规格化后的阶码。
- 可视化：[浮点数加减五步走](../../演示/计算机组成原理/浮点数加减五步走.html)
