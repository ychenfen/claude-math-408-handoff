## 知识点与适用条件

- **平衡二叉树（AVL）**：空树，或者左右子树都是 AVL 且高度差的绝对值不超过 1。
  - 平衡因子 = 左子树高 − 右子树高，只能取 −1、0、1。
  - 判断时把每个非叶结点的平衡因子都写出来（空子树高 0，叶子高 1），出现一个 ±2 就不是。
  - 题目没说是二叉排序树时，还要先检查左 < 根 < 右。
- **森林与二叉树（左孩子右兄弟）**：二叉树的左孩子是原森林的第一个孩子，右孩子是原森林的下一个兄弟。
  - 问「二叉树里的某种关系对应森林里什么」，就把路径上每条边标成左或右，枚举组合再翻译回去。
  - 祖父关系的四种组合：左左是祖孙，左右是父子，右左是叔侄，右右是兄弟。
- **间距指针和快慢指针**：
  - 间距指针：两个指针每次都走 1 步，q 先走 k 步，二者始终相距 k，q 到 NULL 时 p 就是倒数第 k 个。
  - 快慢指针：一个走 2 步、一个走 1 步，用来找中间结点和判断有没有环。
  - 2009-42 的考场写法用两遍扫描，记录里说约 10 分。

## 闭卷自测

### 自测：只看根平衡就够了吗

**题干**：一棵二叉排序树的结构如下：根为 5，左孩子 3，右孩子 8；3 的左孩子 2、右孩子 4；8 没有左孩子，右孩子是 9；9 没有左孩子，右孩子是 10。其余孩子为空。请写出每个非叶结点的平衡因子（左子树高 − 右子树高，空树高 0），并判断它是不是平衡二叉树。（改编题，检验 `408-2009-4` 的判断方法。）

**参考要点**：
- 结点 3 的平衡因子是 1 − 1 = 0。
- 结点 9 是 0 − 1 = −1。
- 结点 8 是 0 − 2 = −2。
- 根 5 的左子树高 2、右子树高 3，平衡因子是 −1。
- 根是平衡的，但结点 8 是 −2，所以不是平衡二叉树。要检查每个结点，不能只看根。

### 自测：迁移｜二叉树中 v 在 u 的左子树里，原森林中是什么关系？

**题干**：森林按「左孩子右兄弟」规则转换成二叉树。若在二叉树中结点 v 位于结点 u 的左子树中（不一定是左孩子），那么在原森林中 v 和 u 一定是什么关系？若 v 位于 u 的右子树中呢？（迁移题，关联 `408-2009-6`，不是原题。）

**参考要点**：
- u 的左孩子是 u 在森林中的第一个孩子。从那里再往左（孩子）或往右（兄弟）走，到达的都是 u 的孩子或更深的后代，所以 v 在 u 的左子树中时，v 一定是 u 的子孙。
- v 在 u 的右子树中时，v 是 u 后面的某个兄弟，或者是这个兄弟的子孙。如果 u 是树根，就是后面某棵树里的结点。
- 方法：把每条边标成孩子或兄弟再翻译。

### 自测：间距指针手推

**题干**：带头结点的单链表数据依次为 10、20、30、40、50，要找倒数第 k = 3 个结点。用间距指针做：p、q 都从第一个数据结点出发，q 先走 k 步，然后 p、q 每次各走 1 步，直到 q 为 NULL。写出每一步 p、q 指向的数据，并说明它和快慢指针有什么不同、快慢指针用在什么问题上。（关联 `408-2009-42`，手推题。）

**参考要点**：
- q 先走 3 步：10 → 20 → 30 → 40，此时 p 在 10。
- 然后一起走：p 到 20、q 到 50；p 到 30、q 为 NULL。答案是 30，即正数第 n − k + 1 = 3 个。
- 两个指针步长相同，始终相距 k。
- 快慢指针一个走 2 步、一个走 1 步，用来找中间结点、判断有没有环。

### 自测：算法｜T4 倒数第 k 个两遍扫描

**题干**：单链表题需要先知道总长度才能定位（倒数第 k 个、中间结点、两条链表对齐）时，想到哪个模板？在脑子里过一遍：带头结点、指针域叫 link，求表长的循环怎么写，失败条件写在哪里，第二遍要走几步？（关联 `408-2009-42`，今天 15:50 复习过暴力版。）

**参考要点**：

```c
int Search_k(LinkList list, int k){
    int n = 0;  LNode *p = list->link;
    while (p != NULL){ n++; p = p->link; }       // 第一遍求表长
    if (k < 1 || k > n) return 0;                // 不足 k 个就失败
    p = list->link;
    for (int i = 0; i < n - k; i++) p = p->link; // 走 n-k 步
    printf("%d", p->data);
    return 1;
}
```

丢分点：失败要 `return 0`，不是打印 0；结构体里 link 要声明成 `struct LNode *`。
