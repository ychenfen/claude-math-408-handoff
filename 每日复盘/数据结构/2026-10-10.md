## 知识点与适用条件

- **叶结点公式**：
  - 两个等式：n = n0 + n1 + … + nm，以及 n = 总度数 + 1（除根外每个结点恰有一条入分支）。
  - 两式相减得 n0 = 1 + n2 + 2n3 + … + (m−1)nm，每项的系数是「度 − 1」。
- **折半查找比较次数**：
  - 看判定树的高度 ⌈log₂(n+1)⌉。
  - 查找成功最多比较这么多次。
  - 按本题记录的口径，查找失败最多也比较这么多次（n = 16 时为 5）。
- **冒泡排序的特征**：每趟结束后，最右端（或最左端）多一个已到最终位置的元素。2010-11 是从前往后比较、最大值沉底。
- **线性探测的两个 ASL**：
  - 成功：每个关键字比较几次，加起来 ÷ 关键字个数。
  - 失败：从散列函数能取到的每个地址（mod 7 就是 0～6）出发，往后比到空位为止，和空位那次也算一次；加起来 ÷ 7。
  - 探测时下标按表长取模，会绕回表头。
- **三次逆置做循环左移**：
  - 写法：reverse(0, p−1)、reverse(p, n−1)、reverse(0, n−1)；或者先整体逆置，再逆置 [0, n−p−1] 和 [n−p, n−1]。
  - 逆置用 `while (l < r)`，交换要用临时变量。
  - 时间 O(n)，空间 O(1)。

## 闭卷自测

### 自测：迁移｜线性探测的成功与失败 ASL

**题干**：关键字序列 (5, 12, 19, 3, 10) 依次插入散列表，散列函数 H(key) = key mod 7，表长 8（下标 0～7），用线性探测法处理冲突，探测地址按表长 8 取模。请画出散列表，并求等概率下查找成功和查找失败的平均查找长度（查找失败时，与空位的比较也算一次）。（迁移检验题，关联 `408-2010-41`，不是原题。）

**参考要点**：
- 表：3 号 3，4 号 10，5 号 5，6 号 12，7 号 19，其余为空。
- 成功：5、12、19、3、10 依次比较 1、2、3、1、2 次，ASL = 9/5。
- 失败：起点只取 0～6（mod 7 能算出的地址），分别比较 1、1、1、6、5、4、3 次。从 3 号出发要比到 7 号再绕回 0 号才遇到空位。ASL = 21/7 = 3。
- 分母是 7，不是表长 8，也不是关键字个数 5。

### 自测：迁移｜叶子数与折半查找次数

**题干**：(a) 一棵度为 3 的树中，有 5 个度为 3 的结点、4 个度为 2 的结点，其余都是叶子，叶子有几个？写出用到的两个等式。(b) 长度为 20 的有序顺序表做折半查找，查找失败时最多比较几次？说明怎样从判定树得到这个数。（迁移检验题，关联 `408-2010-5`、`408-2010-9`。）

**参考要点**：
- (a) n = n0 + n2 + n3，n = 2n2 + 3n3 + 1。相减得 n0 = 1 + n2 + 2n3 = 1 + 4 + 10 = 15。系数是「度 − 1」，不是度。
- (b) 判定树高 ⌈log₂(20 + 1)⌉ = 5，所以最多比较 5 次。要数的是判定树的层数，不是「对半几次」。

### 自测：迁移｜认出冒泡的每一趟

**题干**：对序列 (5, 1, 4, 2, 8) 做冒泡排序，每趟从前往后两两比较，前大后小就交换。写出第 1 趟和第 2 趟结束后的序列，并说明凭什么特征能从「前几趟的结果」认出这是冒泡排序。（迁移检验题，关联 `408-2010-11`。）

**参考要点**：
- 第 1 趟：1 4 2 5 8。
- 第 2 趟：1 2 4 5 8。
- 特征：每趟结束后末尾多一个已到最终位置的最大元素（8，然后 5）。从后往前的冒泡则是开头多一个最小元素。
- 归并的第一趟是两两有序，基数的第一趟是按个位分配，可以据此排除。

### 自测：迁移｜三次逆置改成循环右移

**题干**：n 个整数存在数组 R[0..n−1] 中，要把它们循环右移 k 位（0 < k < n），即 (X0, …, Xn−1) 变成 (Xn−k, …, Xn−1, X0, …, Xn−k−1)。要求时间 O(n)、空间 O(1)，用三次逆置实现：写出三次逆置的下标区间，并用 n = 6、k = 2、R = 1 2 3 4 5 6 验证每一步。（迁移检验题，关联 `408-2010-42`。）

**参考要点**：
- 一种写法：先整体逆置 [0, n−1]，再逆置 [0, k−1]，最后逆置 [k, n−1]。
- 验证：1 2 3 4 5 6 → 6 5 4 3 2 1 → 5 6 4 3 2 1 → 5 6 1 2 3 4，是右移 2 位的结果。
- 也可以先逆置 [0, n−k−1] 和 [n−k, n−1]，再整体逆置。
- 右移 k 位等于左移 n−k 位。

### 自测：算法｜逆置与三次逆置

**题干**：数组题要求「循环移位」「交换前后两段」且空间 O(1) 时，想到哪个基本函数？在脑子里过一遍：逆置 R[l..r] 的循环条件是什么，交换写几句，循环左移 p 位的三次调用各是哪段？（今天 2010-42 作答时用到，关联 `408-2010-42`。）

**参考要点**：

```c
void reverse(int R[], int l, int r){
    while (l < r){ int t = R[l]; R[l] = R[r]; R[r] = t; l++; r--; }
}
void Converse(int R[], int n, int p){   // 循环左移 p 位
    reverse(R, 0, p-1);
    reverse(R, p, n-1);
    reverse(R, 0, n-1);
}
```

丢分点：条件写成 `i < n` 会把交换过去的又换回来，必须是 `l < r`；交换要用临时变量，不能借数组里的一格。
