## 知识点与适用条件

- **KMP（按 01 讲义的改进 PM 法，下标从 0）**：
  - next = PM（各前缀的最长相同前后缀长度）右移一位，首位补 −1。
  - 改进 PM：每列写成「前缀(失配字符)」。从最长相同前后缀往下试：前缀后面紧邻的字符和失配字符不同，就取这个长度；相同就是无效后退，继续试次长的。试到空串时，首字符和失配字符不同记 0，相同记 −1。
  - nextval = 改进 PM 右移一位，首位补 −1。
  - 在第 j 位失配时，模式串右滑 j − nextval[j] 位。
  - aabaab：nextval = −1 −1 1 −1 −1 1，各位右滑 1、2、1、4、5、4，最大 5（第 4 位、即第 5 个字符失配时）。
  - 选项下标从 1 开始时整体 +1（如 0 0 2 0 0 2）。
- **败者树**：
  - 内部结点记的是输掉的那个归并段号，不是关键字。
  - 最上面另有一个结点记冠军，即当前最小关键字所在的段号。
- **折半查找的条件**：顺序存储（能按下标随机访问）加上有序，缺一个都不行。
  - 有序链表只能顺着指针走，不能折半。
  - 静态链表的逻辑次序靠游标，也不能折半。
- **拓扑排序判唯一**：
  - 拓扑排序的四步：按列求入度（Edge[i][j] 给 j 的入度加 1）、入度为 0 的入队、出队并删出边、计数。
  - 判「存在拓扑序列」：看计数是否等于顶点数。
  - 判「唯一」：再加一句，每次出队前队里多于 1 个就返回 0。
- **代码题补法**：
  - 背的是 T1–T11 骨架，59 题用骨架套着练，不逐字背。
  - 真题大多是「一个遍历骨架 + 一个处理动作」。
  - 每天默写 1～2 个骨架拍照批改；错的隔天重默，连续两天对才过关。

## 闭卷自测

### 自测：迁移｜由 nextval 求最大右滑距离

**题干**：模式串 T = "abaabc"，下标从 0 开始。按 01 讲义的方法：先求各前缀的最长相同前后缀长度 PM，右移一位、首位补 −1 得 next；再按「前缀(失配字符)」逐列求改进 PM，右移一位、首位补 −1 得 nextval。在第 j 位失配时模式串右滑 j − nextval[j] 位。写出 next、nextval，求最大右滑距离及发生在第几位。（迁移检验题，关联 `408-2024-6`，不是原题。）

**参考要点**：
- PM = 0 0 1 1 2 0，next = −1 0 0 1 1 2。
- 改进 PM 逐列：a(b) 空串，首字符 a ≠ b，记 0；ab(a) 空串，首字符 a = a，记 −1；aba(a) 最长 a，后面紧邻 b ≠ a，记 1；abaa(b) 最长 a，后面紧邻 b = b 无效，再试空串，a ≠ b，记 0；abaab(c) 最长 ab，后面紧邻 a ≠ c，记 2。
- nextval = −1 0 −1 1 0 2。
- 各位右滑 1、1、3、2、4、3，最大 4，在第 4 位（第 5 个字符 b）失配时。
- 选项从 1 开始时整体 +1：nextval = 0 1 0 2 1 3。

### 自测：迁移｜中缀转后缀

**题干**：把中缀表达式 a * (b + c) − d / e 转换为后缀表达式。说明运算符栈在遇到「(」「)」以及优先级相同或更低的运算符时分别怎么处理。（迁移题，关联 `408-2024-2`，原题干未写入问答，这里不复述原题。）

**参考要点**：
- 结果是 a b c + * d e / −。
- 遇到「(」直接入栈。
- 遇到「)」时，依次弹出运算符直到「(」，括号本身不输出。
- 遇到运算符时，先把栈顶优先级大于或等于它的运算符依次弹出，再把它入栈。
- 扫完后把栈里剩下的全部弹出。

### 自测：迁移｜哪些结构能折半查找

**题干**：下面四种结构都已按关键字组织好：有序顺序表、有序单链表、二叉排序树、散列表。问：(1) 哪些能用折半查找？(2) 哪些能做到 O(log n) 的查找，条件是什么？说明理由。（迁移检验题，关联 `408-2024-5`。）

**参考要点**：
- (1) 只有有序顺序表能用折半查找，因为折半要按下标直接取中间元素，并且要求有序。有序单链表只能顺着指针走，不能折半。
- (2) 有序顺序表的折半查找是 O(log n)。二叉排序树查找次数取决于树高，平衡时是 O(log n)，退化成单支时是 O(n)，而且它不叫折半查找。散列表靠散列函数直接定位，冲突少时接近 O(1)，也不是折半。

### 自测：败者树的结点里存什么

**题干**：k 路归并用败者树选最小关键字。问：(1) 败者树的内部结点里记录的是什么？树的最上面另外那个结点记录什么？(2) 输出一个最小关键字后，从哪个归并段补入下一个记录，沿哪条路径重新比较？4 路归并时每选出一个最小值要比较几次？（关联 `408-2024-11`，概念题。）

**参考要点**：
- (1) 内部结点记录本次比较中败者所在的归并段号，不是关键字值。最上面的结点记录冠军，即最小关键字所在的归并段号。
- (2) 从冠军所在的那一段补入下一个记录，沿它的叶结点到根这条路径，逐个和路径上记录的败者比较。每选一个要比较 ⌈log₂k⌉ 次，4 路是 2 次。

### 自测：算法｜T6 邻接矩阵拓扑排序 TopoCount

**题干**：图题问「有没有环」「拓扑序列是否存在或唯一」，图用邻接矩阵 MGraph 存（numVertices、Edge[i][j] 非 0 表示有边 i→j）时，想到哪个模板？在脑子里过一遍：入度按行还是按列统计，队列怎么入、怎么出，删出边时什么情况入队，最后凭什么判断有环？（今天 20:27 布置默写、20:32 做了代码走读页，关联 `408-2024-41`。）

**参考要点**：

```c
int TopoCount(MGraph G){
    int indegree[MAXV] = {0}, que[MAXV], front = 0, rear = 0, count = 0, n = G.numVertices;
    for (int i = 0; i < n; i++) for (int j = 0; j < n; j++) if (G.Edge[i][j] != 0) indegree[j]++;
    for (int i = 0; i < n; i++) if (indegree[i] == 0) que[rear++] = i;
    while (front != rear){
        int v = que[front++]; count++;
        for (int j = 0; j < n; j++) if (G.Edge[v][j] != 0 && --indegree[j] == 0) que[rear++] = j;
    }
    return count;                       // count < n 说明有环
}
```

丢分点：Edge[i][j] 是给 j 加入度（列和是入度）；判唯一时在 while 里出队前加 `if (rear - front > 1) return 0;`。
