## 知识点与适用条件

- **线索二叉树**：
  - 左孩子为空时，左指针改指遍历序列里的前驱；右孩子为空时，右指针改指后继；用 ltag、rtag 区分孩子和线索。
  - n 个结点的二叉链表有 n+1 个空指针，正好拿来放线索。
  - 先写出对应遍历的序列，再逐个检查空指针。
- **树的结点数与度**：
  - 两个等式：n = Σnk，n = 总度数 + 1。相减得 n0 = 1 + n2 + 2n3 + … + (m−1)nm，二叉树就是 n0 = n2 + 1。
  - 结点的度是孩子个数，所以叶子的度为 0。树的度是各结点度的最大值。
- **完全二叉树**：
  - 高度 ⌈log₂(n+1)⌉。
  - n 为偶数时 n1 = 1，为奇数时 n1 = 0；n0 = ⌈n/2⌉。
  - 从 1 编号：父 ⌊i/2⌋，左 2i，右 2i+1。从 0 编号：父 ⌊(i−1)/2⌋，左 2i+1，右 2i+2。
- **卡特兰数 Cₙ = C(2n, n)/(n+1)**：
  - 前几项：1、1、2、5、14、42、132。
  - 等于 Cₙ 的情况：
    - n 个元素按固定顺序入栈后的出栈序列数；
    - n 个结点的二叉树形态数；
    - 给定先序（或中序、后序之一）的二叉树个数；
    - n 个关键字的二叉排序树个数；
    - n 对括号的合法序列数。
  - n 个结点的树有 Cₙ₋₁ 种形态，森林有 Cₙ 种。
  - 结点带标号又不给任何序列时，是 Cₙ × n!。
- **森林转二叉树**：没有左孩子的结点数 = 森林的叶子数；没有右孩子的结点数 = 森林非叶结点数 + 1。
- **k 叉哈夫曼树**：只有度 0 和度 k 的结点，要求 (n−1) mod (k−1) = 0。余数 u ≠ 0 时补 (k−1)−u 个权为 0 的虚叶子。
- **排序口诀**：用户的口诀基本正确，补了三点：
  - 基数排序是 O(d(n+r))；
  - 希尔排序平均约 O(n^1.3)，最坏 O(n²)；
  - 快排最坏 O(n²)，空间最坏 O(n)。

## 我的卡点与纠正

- 「线索二叉树不是应该指向它的后继吗，为什么还要指向它的前驱」：只记住了后继线索 → 左右空位分别放前驱和后继，有了前驱线索才能沿序列倒着走。
- 卡特兰数四处追问（二叉排序树和括号为什么是 Cₙ、二叉树形态为什么、树和森林、带标号 ×n!）：原因是没分清「数形状」和「往形状里填标号」两步（助手的归纳）。改法：先数形态，再看标号有没有被遍历序列或二叉排序树锁死。
- 「我记得去年考的时候考那个卡特兰树了」：现有资料无法核实，不作为结论。

## 闭卷自测

### 自测：后序线索怎么连

**题干**：一棵二叉树：根 a，a 的左孩子 b、右孩子 c；b 没有左孩子，右孩子是 d；c、d 都是叶子。把它做成后序线索二叉树：先写后序序列，再逐个写出每个空指针变成的线索指向哪个结点（没有前驱或后继就写 NULL）。（题意整理自 `408-2010-3` 的树形，原题四幅选项图在 Markdown 中缺失。）

**参考要点**：
- 后序序列是 d b c a。
- d：左线索为 NULL（没有前驱），右线索指 b。
- b：左孩子为空，左线索指前驱 d；右孩子是 d，不是线索。
- c：左线索指 b，右线索指 a。
- a 没有空指针。
- 规则：左空指前一个，右空指后一个。

### 自测：迁移｜同一棵树换成中序线索

**题干**：同一棵二叉树：根 a，a 的左孩子 b、右孩子 c；b 没有左孩子，右孩子是 d；c、d 都是叶子。改做中序线索二叉树：写出中序序列，并写出每个空指针变成的线索指向哪个结点（没有就写 NULL）。和后序线索相比，哪些线索变了？（迁移题，关联 `408-2010-3`。）

**参考要点**：
- 中序序列是 b d a c。
- b：左线索为 NULL（第一个，没有前驱）；右孩子是 d。
- d：左线索指 b，右线索指 a。
- c：左线索指 a，右线索为 NULL。
- 和后序相比：d 的右线索从 b 变成 a，b 的左线索从 d 变成 NULL，c 的左线索从 b 变成 a、右线索从 a 变成 NULL。
- 方法不变，只是先写的序列不同。

### 自测：完全二叉树的结点计数

**题干**：一棵完全二叉树共有 99 个结点，从 1 开始按层序编号。求：叶子数 n0、度为 1 的结点数 n1、度为 2 的结点数 n2、树高；编号 40 的结点的父结点和左右孩子编号。写出用到的公式。

**参考要点**：
- n 为奇数，所以 n1 = 0；n0 = ⌈99/2⌉ = 50，n2 = n0 − 1 = 49。
- 树高 ⌈log₂(99+1)⌉ = 7。
- 编号 40 的父结点是 ⌊40/2⌋ = 20，左孩子 80，右孩子 81（都不超过 99）。

### 自测：卡特兰数什么时候乘 n!

**题干**：分别求以下数目，并说明是 Cₙ、Cₙ₋₁ 还是 Cₙ × n!：(1) 1、2、3、4 依次入栈，可能的出栈序列数；(2) 先序序列为 a、b、c、d 的不同二叉树个数；(3) A、B、C 三个带标号的结点，不给任何遍历序列，能构成多少棵不同的二叉树；(4) 4 个结点的树有几种形态，4 个结点的森林有几种形态。

**参考要点**：
- (1) C₄ = 14。
- (2) C₄ = 14，因为先序序列把标号锁死了，只剩形状。
- (3) C₃ × 3! = 5 × 6 = 30。
- (4) 树是 C₃ = 5（转成二叉树后根没有右孩子）；森林是 C₄ = 14。
- 口诀：给了遍历序列或者是二叉排序树就是 Cₙ，什么都没给就乘 n!。

### 自测：迁移｜三叉哈夫曼树要补几个虚叶子

**题干**：权值为 1、2、3、4、5、6 的 6 个叶子，构造三叉哈夫曼树（每个非叶结点恰好 3 个孩子）。需要补几个权为 0 的虚叶子？写出每次合并的三个权值和合并结果，求带权路径长度 WPL。（迁移题，改编自 14:37 小节的四叶例子。）

**参考要点**：
- (6 − 1) mod (3 − 1) = 1 ≠ 0，补 (3 − 1) − 1 = 1 个 0。
- 合并：{0, 1, 2} → 3；{3, 3, 4} → 10；{5, 6, 10} → 21。
- WPL = 各次合并结果之和 = 3 + 10 + 21 = 34。核对：5、6 在第 1 层，3、4 在第 2 层，1、2 在第 3 层，5+6+2×(3+4)+3×(1+2) = 34。
- 不补虚叶子时最后一次合并凑不满 3 个，就不是最优的。
