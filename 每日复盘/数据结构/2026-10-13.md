## 知识点与适用条件

- **查找失败的 ASL**：
  - 线性探测：从散列函数能取到的每个地址出发，往后比到空位，空位那次也算；÷ 地址个数。
  - 拉链法：失败次数 = 链长，空链 0 次。空指针算不算一次有两种说法，题目没说时按不算，并在答案里写明。
  - 折半查找、二叉排序树、平衡二叉树：画判定树，补 n+1 个失败结点，比较次数 = 失败结点双亲所在的层数，÷ (n+1)。
- **矩阵压缩存储**：
  - 下标 = 按存储顺序排在它前面的元素个数 + 数组起始下标。
  - 题目没说时，矩阵下标从 1 开始，C 语言数组从 0 开始。
  - 常用式子：含对角线的下三角按行优先是 i(i−1)/2 + j − 1；三对角按行优先是 2i + j − 3。
- **关键路径**：
  - 按拓扑序正推 ve，进来的边取最大。
  - 逆拓扑序倒推 vl，出去的边取最小。
  - 活动的 e = ve(起点)，l = vl(终点) − 时长；e = l 的活动是关键活动。
  - 缩短工期要同时缩短所有关键路径共有的活动，或者每条关键路径上各缩一个。
- **KMP 讲义法**（0 起编号）：
  - next = PM 右移一位，首位补 −1。
  - 改进 PM：从最长相同前后缀往下试，紧邻的下一个字符和失配字符相同就是无效后退。
  - nextval = 改进 PM 右移一位，首位补 −1。
  - 右滑距离 = j − next[j]。
- **代码骨架怎么学**：
  - 先看三句思路，开着「先猜」走读一遍，再看错法和默写自测，第二天白纸闭卷手写拍照批改。
  - 组合用暴力五问：枚举 → T1；记值或次数 → T2；排序或合并 → T3、快排；链表 → T4；树或图 → 遍历骨架。
  - 要背的结构体：Sqlist、LNode／LinkList、BTNode／BiTree、MGraph、邻接表三层，P1 再加 CSNode。

### 自测：迁移｜对称矩阵问到没存的那一半

**题干**：(a) 10 × 10 的对称矩阵 M，元素 m_{i,j} 下标从 1 开始。把下三角部分（含对角线）按行优先存入下标从 0 开始的 C 语言一维数组 N。元素 m_{4,7} 存在 N 的哪个下标？(b) 100 阶三对角矩阵按行优先压缩存入下标从 0 开始的数组，m_{30,31} 的下标是多少？两问都写出「前面存了几个」怎么数。（迁移题，关联 `408-矩阵压缩`，改编自 2018、2016 年选择题。）

**参考要点**：
- (a) m_{4,7} 在上三角，没有存，按对称换成 m_{7,4}。前 6 行存了 1+2+…+6 = 21 个，第 7 行在它前面还有 3 个，共 24 个，下标从 0 开始，所以是 24。式子 i(i−1)/2 + j − 1 = 21 + 3 = 24。
- (b) 第 1 行 2 个，第 2～29 行每行 3 个，前 29 行共 2 + 28 × 3 = 86 个。第 30 行存 m_{30,29}、m_{30,30}、m_{30,31}，m_{30,31} 前面还有 2 个，共 88 个，下标 88。式子 2i + j − 3 = 60 + 31 − 3 = 88。

### 自测：迁移｜拉链法的成功与失败 ASL

**题干**：关键字序列 (5, 12, 19, 3, 10) 依次插入散列表，散列函数 H(key) = key mod 7，用拉链法处理冲突，新关键字插在所在链的末尾，地址 0～6。画出各条链，求等概率下查找成功和查找失败的平均查找长度（失败时与空指针的比较不计）。和线性探测相比，失败 ASL 的数法哪里不同？（迁移题，关联 `408-2010-41`。）

**参考要点**：
- 链：3 号链 3 → 10；5 号链 5 → 12 → 19；其余为空。
- 成功：3、10、5、12、19 依次比较 1、2、1、2、3 次，ASL = 9/5。
- 失败：每个地址的比较次数等于链长，0～6 号依次是 0、0、0、2、0、3、0，ASL = 5/7。
- 不同之处：线性探测要比到空位，空位那次也算；拉链法空链是 0 次。题目没说空指针算不算时，按不算并在答案里写明。

### 自测：迁移｜关键活动变长后关键路径会不会换

**题干**：AOE 网有顶点 0～5，活动（有向边）及时长为：0→1 为 4，0→2 为 6，1→2 为 5，2→3 为 4，2→4 为 3，3→5 为 3，4→5 为 3。(1) 求各顶点的 ve、vl，写出关键路径和长度。(2) 若活动 2→4 的时长从 3 改成 5，关键路径和长度变成什么？（2011 年第 41 题还原出的图，第 (2) 问为迁移改编。）

**参考要点**：
- (1) ve = 0, 4, 9, 13, 12, 16；vl = 0, 4, 9, 13, 13, 16。关键路径 0→1→2→3→5，长度 16。
- (2) ve(4) = 9 + 5 = 14，ve(5) = max(13 + 3, 14 + 3) = 17。关键路径变成 0→1→2→4→5，长度 17；2→3、3→5 不再是关键活动。
- 要点：ve 取进来的最大，vl 取出去的最小，非关键活动变长超过余量后，关键路径就会换。

### 自测：讲义法求 nextval

**题干**：模式串 aabaaba，位置从 0 开始编号。按讲义方法：先写每个前缀的最长相同前后缀长度（PM 表），右移一位、首位补 −1 得到 next；再用改进 PM（紧邻的下一个字符和失配字符相同就是无效后退，继续往下试）得到 nextval。写出 PM、next、nextval 三行。（讲义第四章 p40–47 的例题，局部复习。）

**参考要点**：
- PM = 0 1 0 1 2 3 4。
- next = −1 0 1 0 1 2 3。
- nextval = −1 −1 1 −1 −1 1 −1。
- 例：第 4 位是 a，next 指向的第 1 位也是 a，后退到那里必然再失配，所以继续取第 1 位的 nextval −1。第 2 位是 b，第 1 位是 a，字符不同，保留 1。

### 自测：算法｜逆置（在自己的原代码上改）

**题干**：要把数组一段原地倒过来，或者用三次逆置做循环移位时，想到哪个基本函数？在脑子里过一遍：用 for 写 reverse(R, i, j) 时，for 的初始化部分能不能写 `int i = 0`，循环条件是什么，交换的三句要不要大括号；循环左移 p 位时三次调用各传哪段？（今天 14:48 在用户的原代码上改过，关联 `408-2010-42`。）

**参考要点**：

```c
void reverse(int R[], int i, int j){         // 逆置 R[i..j]
    for ( ; i < j; i++, j--){                // 不重新定义 i，条件 i<j
        int t = R[i]; R[i] = R[j]; R[j] = t; // 临时变量，加大括号
    }
}
void Converse(int R[], int n, int p){        // 循环左移 p 位
    reverse(R, 0, n-1); reverse(R, 0, n-p-1); reverse(R, n-p, n-1);
}
```

丢分点：for 里写 `int i = 0` 会盖掉参数 i；先整体逆置时，两段是 [0, n−p−1] 和 [n−p, n−1]，写成 n−p 和 n−p+1 就会差 1。
