## 知识点与适用条件

- **遍历方式的记号**：N 表示访问根，L、R 表示遍历左、右子树，字母顺序就是访问顺序，规则在每个子树里递归使用。判断方法：看序列第一个结点是谁，再看根出现在哪两段之间。例如根在序列中间，且右子树的结点先出现，就是 RNL。
- **反例要让方法必然出错**：判断「某方法不能求最优解」时，反例里要避免打平。边权相等时方法选哪条不确定，阅卷时可能被认为「也可能选对」。写反例还要把方法走出的路径长度和真正的最短路径长度都写出来作对比。
- **41 的贪心为什么错，Prim 为什么对**：41 的方法只看离当前顶点最近的邻点，局部最优不能保证全局最优。Prim 每次选的是连接已选集合和未选集合的最小边，由 MST 的切分性质保证正确，这是两种「贪心」的区别。
- **链表结构体和遍历**：指针域要声明成 `struct LNode *link`。遍历固定写法是 `p = list->link; while (p != NULL){ …; p = p->link; }`（带头结点时从 `list->link` 出发）。没有指针域就没法往后走，这是 42 退回去用数组的根本原因。
- **返回值和输出要分开**：题目说「输出 data 并返回 1，否则返回 0」，代码要有 `printf` 和 `return 1`，失败时 `return 0`。打印 0 不等于返回 0。
- **42 的评分（凭记忆，未对答案册逐条核）**：一遍扫描（双指针）正确可得满分 15；两遍扫描（先求表长）最高约 10 分。手册 T4 按两遍扫描写。

## 闭卷自测

### 自测：由遍历序列反推遍历方式

**题干**：一棵二叉树：根为 1；1 的左孩子 2、右孩子 3；2 的左孩子 4、右孩子 5；5 的左孩子 6、右孩子 7（其余孩子为空）。N 表示访问根，L、R 表示遍历左、右子树。若遍历得到的序列是 3、1、7、5、6、2、4，遍历方式是 LRN、NRL、RLN、RNL 中的哪一种？说明怎么排除另外三种。（题意整理自 2009 年 408 选择第 3 题，树形按助手记忆描述，以原题图为准。）

**参考要点**：RNL。序列第一个是 3（根 1 的右孩子），先遍历了右子树，所以只剩 RLN、RNL；第二个是根 1，根出现在右子树之后、左子树之前，所以是 RNL。验证左子树 2：先右子树 5（得 7、5、6），再 2，再 4，与序列一致。NRL 第一个应是 1，LRN 第一个应是左子树里的结点；RLN 下 1 应在最后。

### 自测：迁移｜给「每步走最近邻点」的方法构造无歧义反例

**题干**：带权无向图（权值非负）中，从起点 a 到终点 d：方法是每次从当前顶点走向离它最近、且不在已走路径上的邻接顶点，直到到达 d。请自己构造一个反例，要求任何一步都不出现两条边权相等的情况，并写出该方法走出的路径及长度、真正的最短路径及长度。（改编自 2009 年 408 第 41 题，不是原题作答。）

**参考要点**：例如 a–b 权 1、b–d 权 10、a–c 权 3、c–d 权 2。方法从 a 只能走最近的 b（1<3），再到 d，路径 a→b→d 长 11；最短路径 a→c→d 长 5。关键是第一步的最近选择必须唯一，并且之后的代价很大。

### 自测：迁移｜同样是贪心，Prim 为什么能得到最小生成树？

**题干**：方法甲：求起点到终点的最短路径时，每次从「当前顶点」走向离它最近的邻点。方法乙（Prim）：求连通带权无向图的最小生成树时，每次从所有「一端在已选集合、另一端在未选集合」的边中选权最小的一条加入。两者都是每步选最小，为什么甲不一定得到最短路径，而乙一定得到最小生成树？（迁移题，关联 `408-2009-41`。）

**参考要点**：甲只看当前顶点的局部邻边，不考虑后续代价，局部最优不能保证全局最优。乙比较的是整个已选集合和未选集合之间的所有边，由 MST 的切分性质（跨切分的最小边一定属于某棵最小生成树）保证每步选择都安全。两者的区别是比较范围和问题的结构，不是「贪心」本身对不对。

### 自测：算法｜T4 链表先求长度

**题干**：遇到单链表题要「倒数第 k 个」「中间结点」「两条链表对齐」这类需要知道总长度的问题时，想到哪个模板？在脑子里过一遍：带头结点、指针域叫 link 时，求表长的循环怎么写，第二遍走到正数第 m 个结点要循环几次？

**参考要点**：

```c
int n = 0;
LNode *p = list->link;   // 带头结点：从第一个数据结点出发
while (p != NULL){ n++; p = p->link; }
p = list->link;          // 第二遍：走到第 m 个
for (int i = 1; i < m; i++) p = p->link;
```

丢分点：link 必须是 `struct LNode *`；倒数第 k 个就是正数第 n−k+1 个，先判 k>n 返回 0。

### 自测：算法｜倒数第 k 个结点的双指针

**题干**：带头结点单链表（data、link），只给头指针 list，要求只扫描一遍找出倒数第 k 个结点：找到就输出 data 并返回 1，表长不足 k 就返回 0。在脑子里过一遍：两个指针从哪里出发，先让谁走几步，什么时候判失败？（关联 `408-2009-42`。）

**参考要点**：

```c
LNode *p = list->link, *q = list->link;
int count = 0;
while (q != NULL){
    if (count < k) count++;   // 前 k 步只走 q
    else p = p->link;         // 之后 p 跟着走
    q = q->link;
}
if (count < k) return 0;
printf("%d", p->data); return 1;
```

丢分点：失败是 `return 0` 不是打印 0；q 走到 NULL 时 p 与 q 相距 k，p 正好是倒数第 k 个。
