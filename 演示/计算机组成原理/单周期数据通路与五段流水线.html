    为什么单周期能这样

    • 寄存器堆读是自动的、不要信号，写才要 RegWr；数据存储器读也是组合逻辑，只有写要 MemWr（强化 3 p15、p26）。
    • 一个时钟周期里每个部件只能用一次，所以指令存储器和数据存储器必须分开（p12）；单总线做不了单周期（p14）。
    • 控制信号在整个周期内不变；时钟周期由最慢的 lw 决定（p8、p16）。

    RegDst 按强化 3 的约定：RegDst = 1 选 rt，RegDst = 0 选 rd（与部分英文教材相反，做题以题目说明为准）。PPT 对 add、beq 把 ExtOp 写成 0，因为 ALUSrc = 0 时扩展器的输出不被选用，取 0 或 1 都不影响结果，表里记作 x。

    五段流水线时空图

    1. 五段：IF 取指、ID 译码并读寄存器、EX 执行或算地址、MEM 访存、WB 写回。控制信号在 ID 段生成，随段寄存器往后传：EX 用 ExtOp、ALUSrc、ALUctr、RegDst，MEM 用 MemWr、Branch，WB 用 MemtoReg、RegWr（强化 3 p42–52）。
    2. 寄存器前半周期写、后半周期读：同一个时钟周期里 WB 写进去的值，ID 当拍就能读到（强化 3 p54）。
    3. 不转发：后面的指令最早在前面指令 WB 的那一拍做 ID。转发：ALU 结果在 EX 末尾就能送给下一条的 EX；lw 的数据要到 MEM 末尾才有，紧跟的指令仍要停 1 拍（load-use）。
    4. beq：EX 段比较并算目标地址，MEM 段更新 PC（强化 3 p39–40）。选“冻结”时，后面的指令要等 beq 的 MEM 段结束才取，插 3 个气泡。

    斜纹格是阻塞（气泡）：指令停在 IF 或 ID 段不往后走。红字 ← 表示这一段用到了转发来的数据。
