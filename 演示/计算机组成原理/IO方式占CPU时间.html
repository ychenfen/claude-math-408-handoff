I/O 方式占 CPU 时间

程序查询、中断、DMA 三种方式下，CPU 每秒花多少时钟周期在这个外设上，占 CPU 时间的百分之几。全部统一换算成时钟周期再除。下面还有 DMA 三种访存方式的时间轴。对应 2009-43、第八章 PPT p18–22、p53–61，强化 5 p59–65。

这一类怎么做

  1. 每秒几次：中断 = 数据传输率 ÷ 每次中断传送的字节数；DMA = 数据传输率 ÷ 块大小；程序查询 = 题目给的查询频率（或为了不丢数据，按传输率 ÷ 每次传送字节数算）。
  2. 每次多少周期：给的是指令条数就 × CPI；给的是周期数直接用。中断要把“其他开销”（响应、保存现场等）一起算进去。DMA 只算预处理和后处理，数据传送本身由 DMA 控制器做，不占 CPU 时间。
  3. 占比 = 每秒次数 × 每次周期数 ÷ 主频。也可以用时间算：每次花的时间 ÷ 两次之间的间隔，分子分母单位一致，结果相同。
  4. 单位：数据传输率里的 MB/s、KB/s 一般按 10⁶、10³ 算（2009-43 标准答案就是这样）；存储容量的 KB、MB 才是 2¹⁰、2²⁰。还要分清 B（字节）和 b（位）。

    DMA 三种访存方式的时间轴

    DMA 控制器和 CPU 共用主存，冲突时按下面三种办法之一分配。每格是一个存储周期（第八章 p56，强化 5 p60）。题目没说时，408 多数按周期挪用。

    CPU 访存DMA 访存主存空闲

    CPU 停止法那一行：CPU 被整段停下，但 DMA 只在外设准备好数据的周期才用主存，中间的灰格主存空着，这就是它的浪费。

    方式怎么分代价
    CPU 停止法DMA 发停止信号，CPU 让出总线，整块传完再还控制简单；传送期间 CPU 不能访存，外设两次数据之间主存也闲着
    周期挪用每准备好一个字，DMA 挪用一个存储周期，用完立刻还单字传送，CPU 只被打断一个周期；DMA 和 CPU 同时要访存时 DMA 优先
    交替分时每个存储周期分两半，一半给 CPU、一半给 DMA互不等待，但要求存储器足够快，硬件更复杂

    DMA 和中断的区别

    中断DMA
    谁传数据CPU 执行中断服务程序传，软件传送DMA 控制器直接在主存和外设间传，硬件传送
    CPU 花在哪每传一次数据都要进一次中断：响应、保存现场、服务程序、恢复只花在预处理（设主存地址、长度等参数）和后处理（传完发一次中断做校验等）
    和 CPU 争什么争 CPU 的处理时间争总线（主存）控制权
    何时响应指令执行结束后的中断周期每个机器周期（一次总线事务）结束后都可以响应，不必等整条指令结束
