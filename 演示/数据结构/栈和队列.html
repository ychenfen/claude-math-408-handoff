栈和队列：出栈序列、表达式、循环队列

按罗素讲义第三章（p18–29 出栈序列，p38–46 循环队列，p62–73 表达式）和强化第一讲（p48–61）的原题一步步走。统考考过：出栈序列 2009、2010、2011、2013、2020、2022；中缀转后缀和求值 2012、2014、2018、2024；循环队列 2011、2014。

五句话

  1. 后进先出：入栈顺序是定死的，但什么时候出栈随意，所以同一个入栈序列能得到很多种出栈序列。
  2. 判断一个出栈序列：按顺序看每个要出的元素：在栈顶就出栈；还没进栈就一直入栈直到它进来；它已经在栈里却不在栈顶（被压在下面），这个序列就不合法。
  3. 快速判别：出栈序列里不能出现“先出大的，后面两个小的顺序还是从小到大”，比如入栈 1 2 3 时的 3 1 2（3 出来时 1 压在 2 下面）。
  4. 栈容量：模拟时栈里最多同时有几个元素，就是需要的最小容量；容量不够的序列也不合法。
  5. n 个不同元素的合法出栈序列个数是卡特兰数 C(2n, n) / (n + 1)：n = 1, 2, 3, 4, 5 时是 1, 2, 5, 14, 42。

五句话

  1. 两个栈：结果栈 result、临时栈 temp（讲义叫法）。操作数直接入 result。
  2. “(” 直接入 temp；“)” 把 temp 里 “(” 上面的运算符依次弹出入 result，直到遇到 “(”，括号不进 result。
  3. + − * /：只要 temp 栈顶是运算符并且优先级大于等于当前运算符，就弹出入 result，一直比下去；停下后当前运算符入 temp。
  4. 扫完把 temp 剩下的依次弹出入 result，result 从栈底读到栈顶就是后缀表达式。
  5. 后缀求值：数入栈；遇到运算符连弹两个，先弹出的是 a，后弹出的是 b，算 b op a 再入栈。中缀直接求值：照转后缀的做法走，但每从 temp 弹出一个运算符，就从 result 弹两个数算 b op a 再压回。

讲义文字（第三章 p62、强化第一讲 p51）写的是“栈顶优先级更高才弹出”，但讲义所有动画帧同级也弹出，这里按大于等于做。只弹更高的会算错：(2+3)*2−3*(8/4)+5−2 会变成 23+2*384/*52−+−，值成了 1，正确是 7。

五句话

  1. 取模成环：数组 0 到 M − 1，指针后移一律写 (p + 1) % M，走到 M − 1 后回到 0。
  2. 讲义默认约定：front 指队头元素，rear 指队尾元素的下一个位置，初值 front = rear = 0；入队先存再移 rear，出队先取再移 front；队空 front == rear。
  3. 区分队空和队满三种办法：① 牺牲一个单元，队满是 (rear + 1) % M == front，最多存 M − 1 个；② 增设 size，空 size == 0，满 size == M；③ 增设 tag，front == rear 时 tag = 0 是空、tag = 1 是满（入队置 1，出队置 0）。
  4. 长度 = (rear − front + M) % M（rear 指队尾下一位，或 front 指队头前一位时都是这个）。
  5. 约定会变，先读题干：rear 指向队尾元素时，入队先移 rear 再存，要让第一个元素进 A[0]，rear 初值就是 M − 1；这时长度是 (rear − front + 1 + M) % M。
