# TCP 拥塞窗口怎么变

慢开始：cwnd 从 1 起每轮翻倍，但不超过 ssthresh；到达 ssthresh 后进入拥塞避免，每轮 +1。超时：ssthresh = 当时 cwnd / 2，cwnd 回到 1，重新慢开始。收到 3 个重复 ACK：快重传，并进入快恢复，ssthresh = cwnd / 2，cwnd = 新 ssthresh，然后拥塞避免。图中数值是课件示例（ssthresh 初值 16，第 12 轮超时，第 21 轮快重传），单位为 MSS。
