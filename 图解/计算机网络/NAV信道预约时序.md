# 802.11 RTS/CTS 信道预约与 NAV

RTS、CTS、数据帧里各写一个 NAV，都从“本帧发完”算到“ACK 发完”。CTS 中的 NAV = SIFS + DATA + SIFS + ACK，2024-36 代入得 354μs。
